移动应用文件关联同步

将已有移动应用关联到另一端已确认配对的项目文件。原字节通过项目文件同步传输。

正在读取同步状态…

请先独立确认同账号、服务和项目范围的“项目文件同步”，并完成移动端资料同步。文件可能包含敏感内容，文件绑定传输原字节；此绑定只更新应用关联。

按应用名称和平台对应，再以已确认文件配对重映射 ID。最多 100 个应用，每轮处理 20 个关联；继承项目文件单个 20 MiB、每项目 1000 个限制。

应用或文件缺失、清空关联会暂停核对；两端关联不同可选择已核对版本。不删除或重建文件，不改变启停、安装应用或触发执行。

在移动端应用配置中查看关联，在项目文件中下载原字节。暂停或解除后，两端已有文件和关联保留。
