功能测试资料同步

离线时在本地编辑功能测试资料；联网后与绑定账号的网页端同步定义。

按需求、用例、计划编号及完整目录路径匹配，内容不同需选择。同步目录结构、排序、标题、优先级、资料状态、正文、用例类型及有序计划关联。引用在目标重映射。每类最多 100 条，目录最多 16 层，正文每字段最多 20,000 字符，资料不超过 3 MiB。

资料内容会发送到所选账号服务，请核对业务信息。已通过项目文件同步确认且两端完好的文件下载链接会按本端文件 ID 映射；其他项目链接及失效文件暂停相关资料。人员、治理资料、缺陷、版本、文件和执行记录保留各端。同步不创建执行，删除不传播，改名按新路径或编号处理。

只同步基础资料和计划定义；已有标识、人员、治理关联及执行记录保留各端。不会创建执行或复制文件。缺失或冲突的父目录、需求、用例会暂停相关依赖资料。
