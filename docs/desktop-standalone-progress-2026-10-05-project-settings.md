# 项目设置：项目切换、表单隔离与环境参数迁入账号

状态：任务中心于 2026-10-05 获用户审核通过。本轮项目设置实现、隔离回归、真实双端流程、升级及最终内部包验证已完成，于 2026-10-05 获用户审核通过；现已进入系统设置模块。通知集成仍待后续审核授权。

## 范围与行为

- 路由实际使用 `ProjectSettingsPage.vue`；旧 `ProjectAccessPage.vue` / `ProjectParameterPage.vue` 未被路由使用，不修改这些遗留页面。项目设置包含项目信息、成员、参数/密钥、文件和项目日志；环境定义管理入口仍在原系统设置页面。
- 修复原页面没有监听项目切换的问题：顶部及侧栏选择后刷新、清空旧列表及筛选，关闭旧表单。资源和日志各有请求序号与项目/视图检查，页签切换及卸载使迟到结果失效。列表失败有可见错误和重试，不继续展示另一项目的数据。
- 保存项目信息、成员和参数/密钥使用等待式弹窗钩子，失败保留输入。请求提前捕获原项目、目标标识与字段，再读取 CSRF；去重提交。项目或表单变化后旧回调不能关闭新表单；成功后刷新期间又打开新表单也受保护。账号选项读取失败可见，并保留手工账号输入。
- 文件上传在读取 CSRF 前捕获原项目；删除成员、参数、密钥及文件去重提交并使用原请求路径；保留既有删除确认。加载环境期间不打开参数表单，避免将临时空列表误判为“没有环境”。保留原成员创建和权限契约，本轮不变更账号策略。
- 环境创建、编辑、设默认、删除和参数/密钥写入，与迁入事务共用项目行锁。并发设默认不会产生多个默认环境；旧默认取消时递增其版本，过期编辑返回 409。原版本校验、默认环境不可停用/删除及执行引用保护保留。

注册账号原先的“操作日志”调用系统管理员专用全局接口，被拒绝。新增 `/api/v1/projects/{projectId}/audit-logs`，按路径项目鉴权，只返回页面需要的摘要字段，不返回详细 payload 或客户端 IP。原全局接口保持系统管理员限制；另一个项目即使通过 query 指定，也不能绕过路径范围。

## 一次性迁入账号

- 独立原生入口“项目环境与参数迁移”，从当前本地来源项目复制到明确选择的在线账号目标项目。协议 V1、范围 PROJECT_SETTINGS，100 个环境 / 1000 个普通参数、32 MiB；HTTP 流式请求 33 MiB。冻结预览 10 分钟，账号或服务变化重新预览，原生确认默认取消。
- 环境包含名称、标识、基础地址、说明与启用/源默认状态；普通参数包含环境、键和值。敏感密钥只携带排除数量，不携带名称、密文或明文；用户在目标账号重新填写。本轮提前询问是否另行勾选密钥，未收到其他选择，按已说明的默认方案实施。
- 目标生成新标识，由目标账号拥有，新环境版本为 1。已有目标默认环境保留，不将来源默认环境改成目标默认。同标识环境仅在名称、基础地址、说明和启用状态一致时复用（默认状态按目标保留）；同键普通参数相同值复用，不同值或与密钥同名返回 409，整批回滚。错误不含参数值/密钥值。初始同名 test 环境若定义不同，也明确冲突，需用户调整定义后重试，不自动覆盖。
- BASE_URL 由环境基础地址生成，不作为独立普通参数导出；普通参数引用没有定义的环境时，目标须已有该环境，否则报冲突。沿用项目管理员和测试负责人写权限，不扩大 TESTER/VIEWER 的配置写权限。
- UUID/SHA-256 回执、项目锁保证相同重试不重复创建；不同 payload 复用请求键被拒绝，审计写入失败也整批回滚。复用已有配置不修改其身份、版本或更新时间。
- 不复制项目身份、成员权限、访问令牌、旧审计日志及密钥；文件仍使用之前完成的文件迁移。新操作产生目标自己的审计。本地原件不动，目标后续编辑不自动同步回本地；本轮仍不宣称离线自动双向同步完成。
