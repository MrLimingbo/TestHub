# 阶段 9 · 节点 3：可信插件注册表与企业适配器边界

## 交付内容

- 新增系统级可信插件注册表、签名密钥、插件版本发布记录和企业适配器配置迁移（V47）。插件升级记录独立保留，升级完成后自动回到停用状态，必须由系统管理员重新启用。
- 插件包采用原始 JSON 清单 + Ed25519 detached signature：系统只接受已启用的 X.509 Base64 公钥，逐字节校验清单签名，并校验 SHA-256 包摘要。
- 插件清单严格限制插件类型（Runner、Integration、Reporter）、语义化版本、入口格式和最小权限集合；禁止控制面加载、执行或动态链接第三方插件代码。
- 支持可信签名密钥登记、撤销与重新启用；撤销只阻止后续包安装，不会静默改变现有插件，所有操作写入审计日志。
- 支持插件安装、版本升级、启用和停用。仅系统管理员可修改；所有已登录用户只能读取已安装插件和适配器摘要。
- 建立 OIDC、LDAP/Active Directory、企业微信、钉钉、Jira、禅道的声明式适配器目录。敏感配置整体使用 AES-GCM 加密保存，读取接口只返回配置字段名，绝不返回凭据值。
- 适配器地址限制为 HTTPS 标准端口；LDAP 仅接受 LDAPS 标准端口。控制面只做配置校验和加密保存，目录同步、通知投递和缺陷双向操作必须由可独立禁用的隔离适配器进程执行。
- 插件中心从 Mock 页面替换为可操作页面：可信插件表、签名密钥抽屉、签名包安装表单、插件启停、企业适配器目录及 OIDC/LDAP 等配置表单均可访问。

- `./mvnw -q -pl services/platform-api test`：全套通过，并验证 47 个 Flyway 迁移。

- 浏览器预览：`/plugins` 路由、插件空态、企业微信/钉钉/Jira/禅道/OIDC/LDAP 适配器目录、OIDC 加密配置表单、签名密钥抽屉及 Ed25519 公钥登记表单均正常显示。

## 生产边界

本节点没有把 OIDC 登录、LDAP 同步、企业消息发送或缺陷同步直接塞进控制面，也没有执行任何第三方插件代码。这些操作应由后续独立适配器/插件工作进程承接，并在部署时分别配置网络出口白名单、凭据轮换、限流与故障隔离策略。
