# TestHub 安装即用：任务登记离线双向同步

日期：2026-10-05。上一模块“真实执行统一列表”已获用户审核通过。本轮任务登记同步已完成并获用户审核通过；其余业务资产同步及正式多平台发行继续保留待办。

## 使用方式与范围

桌面“任务中心”新增“任务登记同步”入口，应用菜单也可打开。先连接账号服务并登录，在原生窗口明确选择一组本地项目、账号项目，预览首次上传和下载数量，再确认绑定。默认不启用，不会自动上传整个本地工作区。

本轮同步手工任务登记的类型、名称、状态及进度。首次合并保留双方登记，同名记录分别保留，随后根据本机保存的标识映射更新对应记录。活动状态按登记保留，不启动测试或创建 Runner 请求。真实执行、历史报告、工件、文件、其他业务资产及账号凭据不在本轮范围内。每个项目最多 1000 条，一台电脑本轮支持一组项目绑定。

应用运行时每 30 秒检查两端；断网期间在本地工作区编辑，联网且绑定账号会话有效后自动上传/下载。也可立即同步、暂停、恢复或解除绑定。退出程序后不运行后台同步；重启后读取持久绑定，同一账号会话失效时需重新登录。账号或服务切换、写入权限失效均停止发送。

两端同时修改同一登记时，保留双方版本并显示名称、状态和进度供选择，用户确认后才更新另一端。确认时重新读取并核对版本，变化则要求重新审核。其他无冲突登记可以继续同步。已有映射的一端记录缺失时提示核对，不自动删除或重新创建；本轮未新增业务删除接口。

## 一致性与数据保护

- `GET /api/v1/projects/{projectId}/tasks/sync?expectedUserId=...` 返回项目内最小登记投影；`POST` 支持新增及带目标版本的更新，不提供执行能力。
- 两端均检查登录用户、项目和写入角色；仅有读权限的 VIEWER 不能启用同步。POST 使用 CSRF，拒绝未知字段、重复操作标识、无效类型/状态/进度、跨项目任务及超限正文。
- 提交前将同一请求及其 UUID 加密写入本机；服务端回执持久保存结果标识。响应丢失或重启后重发原请求，避免重复新增。目标版本冲突返回 409，整个批次回滚，再读取双方资料。
- 本机 `task-sync.bin` 由系统安全存储加密，使用临时文件、原子替换和持久化写入；Mac 文件权限为 0600。没有存储密码、访问令牌或复制浏览器凭据。HTTP 请求不跟随重定向，响应限 1 MiB；服务报错不回显内部内容。
- 同步操作与备份、恢复、资料迁移、执行设置保存共用原生互斥锁。同步映射位于工作区之外，不随工作区备份迁移。恢复备份前持久暂停旧绑定，并要求重新预览绑定，防止旧基线和待发送请求作用于回退后的数据库。
- 解除绑定保留两端业务登记，清除本机同步映射及待发送记录；原生提示需先核对结果不确定的请求。重新绑定将重新合并，可能新增同名登记。

新增回执表：H2 `V20__task_sync_receipt.sql`，MySQL `V77__task_sync_receipt.sql`。原有任务及迁移协议保持兼容。
