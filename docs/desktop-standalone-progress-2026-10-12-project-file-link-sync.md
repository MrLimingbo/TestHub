# TestHub 安装即用：跨模块项目文件链接双向同步

日期：2026-10-12。上一模块“项目文件持续双向同步”已获用户审核通过。本模块完成实现、隔离验证及阶段测试数据清理，随后已获用户审核通过。

## 行为与边界

需求、用例、计划、缺陷、项目版本及执行历史中的项目文件下载链接，现在可随已有资料同步双向转换。文件必须先在“项目文件同步”中由用户逐一确认配对；运行时还会重新核对两端文件均存在、项目范围和 SHA-256 内容一致。桌面端用稳定来源键比较正文，在写入本地或网页时换成各自真实的项目 ID 与文件 ID，因此两端继续编辑同一条资料不会因为物理路径不同而反复覆盖。

未配对、已删除或重建、内容改变、跨项目、外站 URL 内嵌、编码路径以及伪造来源键都不能获得映射，相关资料暂停并显示冲突；其他文件和资料继续同步。服务端同步写入只接受当前项目中确实存在的规范相对下载路径，并拒绝失效及混合编码的项目路径。原有权限、修订校验、回执重试、冲突与备份恢复暂停机制沿用。未新增数据库迁移，仍为 H2 V37／MySQL V94。

桌面四个同步工具补充了“先确认文件配对”的提示。文件同步本身仍遵守用户选择：一端删除已同步文件时暂停该文件、等待人工核对，不自动删除或重建另一端。安装包对其他用户开放、账号公网注册与同步、Mac Intel／Windows 干净机验证均不属于本模块的完成声明。
