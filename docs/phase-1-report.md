- Vue 3 + TypeScript + Vite + Arco Design + Pinia 工程骨架。
- 登录、工作台、组织/项目切换、全局导航、权限占位和用户菜单。
- 功能测试、接口设计、接口调试、接口自动化、Mock、性能测试、报表、项目/系统设置、审计、通知、任务中心、Web/移动自动化与插件中心页面。

- ESLint：通过，无错误或警告。
