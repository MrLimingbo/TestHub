# 质量报告项目筛选契约

2026-11-04，D21-A / OBS-13-E019。适用于GET `/api/v1/reports/quality`及`/api/v1/reports/quality/export`，不改变定时计划的显式项目集合规则。

省略`projectIds`沿用全部可访问默认范围，不因显式列表的50个上限而拒绝超过50个项目的默认范围。显式提供该参数时，每个query值按CSV拆分，token可有首尾空白；按第一次出现顺序去重，去重后最多50个唯一项目。无权限仍403，查询与CSV范围一致。

显式空串、空白、无等号的空键和任一空CSV段均返回400。头/尾/连续逗号、只有逗号的值、重复query键中夹带的空值或空段也遵守同一规则；不得丢弃后回退到默认集合。解析层保留原始重复query值，服务层使用保留尾空段的拆分；格式或权限拒绝时不产生CSV成功审计或返回项目数据。

合法写法包括单值、逗号列表、重复query键，以及这些形式的组合。URL编码在HTTP边界解码一次，随后统一trim、校验和去重；查询与导出均走同一服务解析流程。成功CSV仅对实际纳入的项目记录原有导出审计。

前端可访问项目不超过50时初始全选显式发送当前合法范围；清空时省略参数并提示默认全部。超过50时必须先选择1至50个项目，空选择暂停查询和导出；不得在本项增加空集合报告语义。本轮不修改原有页面行为。

先行用例、原始URL复现与结果见[本轮报告目录](test-reports/2026-11-04/d21-report-filter-fixes-r1/README.md)。12项环境补齐及独立升级关闭超时风险不在本项实施范围。
