# 阶段 5 · 节点 5.13：租约索引绑定运行时快照摘要

## 交付内容

- 可信 Runner 校验短时租约时，内部索引增加运行时快照是否存在、快照 SHA-256、非敏感变量数量及已保留环境密钥名称数量。
- 索引继续绑定同一任务、执行、Runner、截止时间和执行清单；旧执行没有快照时以明确的不可用标识兼容。
- 接口自动化页面的 Runner 边界说明同步标注该能力，仍明确声明运行时配置与用户内容执行关闭。

## 安全边界

- 新增字段全部为元数据；不包含变量名之外的取值、密钥值、密文、请求内容、脚本或租约明文。
- Runner 仍不会自动领取或校验租约，控制面仍无运行时配置领取端点。

## 验收建议

1. 确认可信 Runner 的说明包含“快照校验和/计数”。
2. 集成测试确认租约索引能返回快照摘要，且响应不包含内部非敏感变量取值。
