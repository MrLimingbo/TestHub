# 阶段 5 · 节点 5.6：场景执行清单与安全变量快照

## 交付内容

- 新增 `api_automation_execution_manifest`，与执行任务一对一绑定，并携带组织、项目、场景及版本作用域。
- 在创建执行任务的同一事务中冻结安全清单、写入 SHA-256 校验和、Outbox 和审计记录；任一写入失败会整体回滚。
- 清单仅存储步骤 ID、类型、配置项名称，以及场景变量、项目参数和环境密钥的名称/来源元数据。
- 新增只读接口：`GET /api/v1/projects/{projectId}/api-automation/executions/{executionId}/manifest`。
- 自动化任务详情抽屉增加“已固化执行清单”，可查看版本、环境、计数、校验和和变量来源；UI 不展示任何取值。

## 安全边界

- 清单、审计记录、Outbox、Redis Stream、Runner 日志均不会写入环境密钥、项目参数值、场景变量值、步骤配置值、请求 URL、请求体或脚本文本。
- 本节点仍不让 Runner 读取或执行场景；`manifestRef` 继续是兼容 v1 协议的场景版本引用。

## 验收建议

1. 在“接口自动化场景”选择一个场景并提交预检任务。
2. 打开任务“详情”，确认“已固化执行清单”显示版本、环境、校验和及变量来源，且只显示变量名。
3. 将场景变量、项目参数或环境密钥填入明显的测试值后再次提交，确认详情、日志和任务状态中都不出现该测试值。
