# 阶段 5 / 节点 32：并行组脱敏执行报告

## 交付内容

- 执行报告升级到版本 5，新增 `parallelGroups` 父步骤聚合数组。
- 每个并行组只提供配置分支数、最终完成/成功/失败数、尝试与重试次数、逻辑请求序号窗口和累计耗时。
- 控制面从已持久化的脱敏 HTTP 结果按 `PARALLEL` 父步骤聚合；同一逻辑请求仅以最高尝试号计入最终结果。
- 执行详情页新增“并行请求组汇总”，展示分支完成情况、失败数、重试数、序号范围和耗时。

## 安全边界

- `parallelGroups` 不包含 URL、HTTP 方法、请求或响应、状态文本、分支配置、变量、密钥、日志或其他自由文本。
- 页面只使用冻结父步骤标识和报告中的固定数值；不回读场景配置。
- 通过 Redis Stream 输入的 HTTP 结果仍由控制面根据冻结清单验证步骤和方法后才会持久化。

## 验证

- `ApiAutomationExecutionFlowTests#aggregatesBoundedParallelRequestsInTheExportSafeReport` 验证最终尝试折叠、重试计数、范围与耗时，并断言报告不泄露 URL 或变量模板。
- 前端在窄屏下将多余统计标签折到第二列，保持执行详情可读。
