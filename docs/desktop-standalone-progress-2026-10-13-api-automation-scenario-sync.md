# 接口自动化场景与固定历史引用同步（已审核通过）

本模块新增 `API_AUTOMATION_SCENARIO_SYNC / 1`。接口自动化页的“场景同步”按钮和原生菜单可打开绑定窗口，预览并确认本地项目与账号项目后，持续双向同步场景当前定义、步骤、脚本和变量，以及这些步骤实际固定引用的公共步骤／子场景历史内容。按场景及引用来源名称匹配，最多 200 个场景、8 MiB；未引用的旧修订、执行历史、定时任务与 Webhook 不在本协议范围。同步本身不执行脚本或创建执行任务。

按用户已确认的“保留历史引用，追加新版本”，传输中的固定引用携带历史内容，不直接复制两端不同的资料 ID 或版本号。目标已有相同内容时按内容摘要复用对应本端修订；没有时追加历史，再保存来源资料原来的当前内容。两端版本号可能不同，来源资料的本端版本号可能增加；已有历史与其他场景的固定旧引用不改写。新子场景可以与父场景在同批事务复制，所有已提交版本均有真实历史快照，当前场景相互引用各自的旧原始步骤时也能映射。单个引用来源最多核对 1000 个修订，接近上限时暂停追加。

公共步骤来源应先通过已审核的基础资料同步建立。固定子场景历史沿用原业务约束：不包含嵌套引用或前后置脚本；当前根场景的脚本照常保存。缺失或失效的引用、名称大小写不同、目标环境缺失或停用会暂停涉及场景；已有子场景当前内容冲突不阻止父场景保存有效的固定旧历史。项目文件下载链接复用已确认的文件配对，递归映射当前定义及固定历史中的链接；未配对、失效、删除或跨项目链接暂停相关场景，无关场景继续同步。

首次同名不同内容和双端同时编辑要求选择保留一端。删除、改名、同名重建和引用来源身份变化暂停核对，不自动删除或重建。桌面状态、基线及未确认请求加密保存；回执丢失后使用原请求安全重试，避免重复追加历史。账号、项目和服务变化停止写入；恢复备份后绑定持久暂停，必须解除后重新预览。绑定及冲突确认展示发送范围和完整内容。

后端新增 H2 V40／MySQL V97 的独立幂等回执表，具备账号、项目权限、CSRF、项目锁、快照修订和整批事务保护。前置 10 MiB 请求限制覆盖声明长度和 chunked 请求。迟发校验失败会回滚新场景占位、追加历史、当前版本及回执；同一请求重放保留稳定结果。

验证完成：隔离 H2 后端全量 598 项，独立 MySQL 8.4.10／Redis／文件存储定向 40 项，前端 288 项、桌面 513 项，lint 和生产构建通过。新增后端场景用例覆盖同批缺失子场景、不同端版本号、相互固定旧引用、历史名称保留、失败回滚、权限及回执；桌面用例覆盖依赖暂停、来源重建、删除、冲突、文件映射、环境恢复、响应丢失与备份恢复保护。

源码桌面和内部 Mac arm64 包各通过 9 项真实离屏流程：显式文件配对、原生场景绑定、双向固定历史映射、来源当前内容及旧引用保留、下载转换后的项目文件、网页修改回传、人工冲突选择、删除暂停和加密状态。两者各通过 3 项真实 V39→V40 升级检查，原账号与记录 ID、公共步骤、场景固定引用、接口版本、文件字节及加密同步文件保留，原基线数据库未改动。包内 229 个原生、后端及生产前端文件 SHA-256 与源码构建一致。

所有验收窗口隐藏、不可聚焦并离屏，可见窗口违规和意外弹窗均为 0。本阶段测试账号、工作区、数据库、日志、备份、基线、临时包、测试报告和旧运行时副本已清理，仅保留脱敏摘要及复用脚本，见 `.testhub/api-automation-scenario-sync-module-20261013/final-verification.json`。当前运行时和用户数据保留，未提交或推送 Git。
