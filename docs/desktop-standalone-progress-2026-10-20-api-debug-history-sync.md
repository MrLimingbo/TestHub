## 行为与边界

- 新增两个独立的桌面绑定：“接口调试历史同步”和“脱敏重放草稿同步”。默认未绑定，分别勾选确认、预览项目／数量、通过默认取消的原生确认后启用；历史绑定不会顺带启用模板绑定。应用运行期间每 30 秒检查，每轮最多处理 20 项，剩余数量可见。缺少对应历史的模板暂停；已暂停的模板不会持续占满前 20 个位置、阻塞其他新记录。
- HTTP、GraphQL、SOAP、WebSocket、gRPC 的只读历史摘要保留来源项目／记录、协议、方法、结果、原时间、状态码、耗时和响应字节。目标只保留可解析的 scheme、主机和端口，路径显示 `/…`；无法解析主机时显示隐藏标记。请求／响应正文、错误原文、认证、原 URL 路径与查询不进入摘要。
- 模板独立确认，只有两端对应历史摘要一致时才能复制。认证、Cookie、敏感 JSON 字段和已知项目密钥值转为 `SYNC_REVIEW` 占位符；保留已有变量引用。JSON 正文、gRPC 请求 JSON 和 WebSocket 订阅按字段处理；非 JSON 正文、GraphQL 查询、XML Envelope 需要重新补齐。环境与 gRPC 描述符引用清空，项目文件 URL 转为待核对占位符；WebSocket 自动重连关闭。
- 脱敏模板仍可能包含业务数据、非敏感路径和参数，不能视为普遍匿名化结果。确认界面明确提示这一点；使用者须检查目标、内容、环境、文件和描述符。原有本地历史及加密草稿不改写，原有保存、载入、重发与执行协议保持原来行为。
- 接口快捷请求页新增“同步历史与模板”入口，展示导入记录、原始来源、SHA-256 和只读 JSON 下载。载入模板不会发送；必须勾选核对并清除活动请求中的 `SYNC_REVIEW` 占位符，再单独点击发送／连接／调用。切换项目清除模板目标和核对状态；存在活动连接／流时先结束会话。已结束的旧会话不会阻塞载入新模板。
- 同步副本独立保存，不能编辑、覆盖、删除或自动重建；不创建原生执行，也不重复计入既有执行统计。修改副本内容、删除原端／目标、同源重复或草稿对应历史变化均暂停。原有一次性迁移来源 ID 保留，不误认作新源。

## 接口、数据与一致性

新增 `/api/v1/projects/{project}/api-debug/{history|replay-drafts}/archive`：

| 方法／后缀 | 用途 |
| --- | --- |
| GET 根路径 | 当前项目索引，供用户查看 |
| GET `/sync?expectedUserId=…` | 核对当前账号的同步索引与整体修订 |
| GET `/{originProject}.{originHistory}` | 获取经过权限／完整性验证的摘要或模板 |
| GET `/{key}/export` | JSON 附件下载；no-store、nosniff |
| POST `/sync` | 携带原 UUID、当前账号、预期整体修订与逐项 SHA-256 的不可变复制 |

全部要求当前项目写入权限，写操作保留 CSRF；沿用共享错误封装。严格校验字段、JSON 类型、来源、协议、时间、摘要和模板结构；不接受活动任务、额外正文或未清除的本端引用。单项最多 1 MiB，单个请求最多 4 MiB／20 项。解析前限制请求体；索引在读取原生正文前检查数量／存储估算：原生最多 1000 条、8 MiB；每类副本最多 1000 条、加密存储 12 MiB；合并索引最多 1000 条。超范围暂停，不截断。

H2 V49／MySQL V106 新增独立 archive／receipt 表。目标用自己的密钥重新加密整个同步项；明文索引只保存脱敏摘要元数据。项目锁、整体修订 CAS、原始 UUID 与请求摘要、原子回执防止并发覆盖与重复创建。重放已确认回执仍检查副本是否存在且未变化，不能重建已删除副本。

桌面两种绑定、基线、冲突和待确认请求分别加密保存。状态 IPC 只返回 pending 布尔值，远端页面只暴露打开原生界面的入口，全部修改权限限于对应的可信原生顶层页面。回执丢失时跨重启保留原 UUID／原请求；409 不清除不确定提交，来源／账号／服务变化时停止重试。加密备份恢复后，两种绑定持久停用并要求重新绑定。
