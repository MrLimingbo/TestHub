# 阶段 5 节点 15：受限 HTTP 场景编排与脱敏逐请求结果

完成日期：2026-07-15

## 交付内容

- API 自动化场景的 `REQUEST` 步骤支持编辑 HTTP 方法、地址、正文和内容类型；`GET`、`HEAD` 携带正文会在保存时被拒绝。
- 不可变执行清单升级为 v3，新增不含敏感内容的步骤显示名称与 `REQUEST` 方法，用于结果完整性校验。
- 独立 API Runner 对每次已尝试的受限 HTTP 请求发布严格字段的 Redis Stream 结果；控制面迁移 `V19` 将结果按组织、项目、执行和序号持久化。
- 执行详情新增逐请求结果区，只展示步骤、方法、成功/失败、状态码、耗时、Runner 与时间；不展示 URL、正文、响应、请求头、Cookie、变量值或密钥。
- 控制面仅接受与冻结 v3 清单中的 `REQUEST` 步骤及方法完全匹配的结果，且以 Stream 记录 ID 与执行内序号去重。

## 安全边界

- 该节点没有开放脚本、请求头、Cookie、重定向、数据库步骤、环境密钥或任意自由文本回传。
- HTTP 执行仍默认关闭；只有控制面和受信任 Runner 显式启用、完成签名认证并满足 Origin 白名单时才会发出网络请求。
- Runner 再次校验工件方法、正文大小、Origin 与地址约束；连接前失败以无状态码的失败结果表示。

## 验证范围

- 前端 lint、单元测试与生产构建。
- Node API Runner 协议和执行测试，覆盖成功、非 2xx、无响应失败及结果不携带 URL/正文/响应内容。
- Spring Boot 全量测试，覆盖 Flyway V19、结果流字段拒绝、冻结步骤/方法校验、去重与项目权限读取。
- 浏览器预览：API 自动化页面可编辑请求正文和内容类型，执行详情可展示脱敏逐请求结果区域。
