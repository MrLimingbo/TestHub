# TestHub 安装即用：通知模板离线双向同步

日期：2026-10-08。上一模块“项目环境与普通参数离线双向同步”已获用户审核通过。本轮通知模板同步已完成，并于 2026-10-08 获用户审核通过；其余范围继续保留待办。

## 范围与使用

桌面“通知与集成”页和应用菜单新增“通知模板同步”。连接账号服务并登录后，选择本地项目与账号项目，预览首次上传、下载、冲突及排除地址/密钥数量，再通过默认取消的原生确认建立绑定。默认不启用，本模块支持一组项目绑定；任务登记、项目配置和通知模板三个绑定可独立共存。

按模板名称匹配，同名同内容复用，同名不同内容或两端同时修改保留双方并要求选择。同步事件编码、主题和正文，新模板同时复制名称和通道；已有模板标识、通道、接收地址、签名密钥与启停状态保持各端设置。新模板停用且没有地址或密钥。通道不同或名称仅大小写不同时，要求在各端手动统一，不允许选择一个版本自动切换投递通道。模板名称修改按新名称处理，旧名称缺失会提示核对。

应用运行时每 30 秒检查新建和更新；断网仍可本地编辑，联网并恢复同一绑定账号会话后自动重试。支持立即同步、暂停、恢复、解除绑定和冲突选择；确认期间内容再次变化则停止。删除不自动传播，也不自动重新创建。解除绑定仅清理同步元数据，保留两端业务资料。退出应用后没有后台同步。

同步本身不发送通知，不复制地址、密钥、网络授权、投递队列、历史、测试资产或质量报告计划。已有启用模板未来按各端原有配置使用同步后的定义，这一范围在原生绑定确认中说明。主题、正文会发送到所选账号服务，界面要求核对其中业务信息。邮件、企业微信和钉钉仍为模板定义，不据本轮同步声明已接入实际发送。

每个项目最多 1000 个模板；快照最多 3 MiB，请求和响应最多 4 MiB。合并后的数量与字节预算包括冲突双方较大版本，缺失但仍待核对的基线也计入数量。超过范围时停止发送，需核对资料或解除绑定重新预览。

## 数据保护与一致性

- 新增 `/api/v1/projects/{projectId}/notification-templates/sync` 的 GET 快照与 POST 新建/更新批次。检查精确账号、项目和现有写入角色 SYSTEM_ADMIN、ORG_ADMIN、PROJECT_ADMIN、TEST_LEAD；POST 要求 CSRF，严格拒绝未知字段、尾随 JSON、重复名称/操作标识、无效定义和超限正文。
- 快照 SQL 仅读取定义及地址/密钥是否存在的布尔标记，不读取地址或密钥列。摘要覆盖模板标识、定义、启停、更新时间及配置存在标记；更新 SQL 仅修改事件、主题、正文、操作者及更新时间，不触碰投递配置。
- 同步与原 CRUD、一次性迁移共用项目锁。目标快照过期、大小写/通道冲突、数量/最终快照超限或审计失败时整批回滚。新模板停用创建，任何配置变更不会建立投递记录。
- POST 前持久化准确请求与 UUID，系统安全存储加密并原子写入 `notification-sync.bin`，权限 0600。服务端项目/账号/requestKey 唯一回执，使已提交但响应丢失的重启重试返回原结果，不重复新增、不覆盖后续编辑；更换载荷不能复用请求标识。
- 复用已审核的系统加密存储与原生 IPC/HTTP 层。只信任准确原生页面及主框架，远程业务页面仅有打开入口；对应服务隔离会话、禁止重定向、超时/响应有界，报错不回显内部内容，不保存密码、令牌或浏览器凭据。
- 三种同步与迁移、执行设置、备份恢复共用互斥保护。恢复备份在切换数据库前持久暂停三个绑定并要求重新预览，同步元数据位于工作区外，不随备份分发。

新增 H2 V22 / MySQL V79 `notification_sync_receipt`，不修改旧模板、投递 API、业务表或旧同步文件格式。不增加依赖。
