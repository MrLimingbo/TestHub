## 用户目标

macOS / Windows 用户安装 TestHub 后即可使用，不需要维护者提供后台地址，不要求用户自行安装数据库、缓存、Java、Node.js 或 Docker。保留现有已完成功能及其数据契约。基线正式桌面版 0.2.0 是连接现有服务的客户端；本轮内部实验包已经包含本地后端，尚未通过正式分发门槛。

## 已确认的产品选择

1. 默认直接进入个人本地工作区，无需注册；可选注册/登录，账号数据需要与该账号的网页端同步，同时保留企业服务模式。
2. 浏览器、JMeter 等较大执行组件首次使用时自动下载。
3. 未登录数据只存本机，支持备份/迁移；登录后的账号同步属于本期范围，不能以仅有本地备份代替。

网页端联调使用用户现有开发入口 `http://localhost:5173/login`，API 由 Vite 代理到本机后台。后续云端地址可配置；不能把 localhost 写成其他用户的默认在线服务。服务端自助注册需显式开启，不改变现有企业部署默认策略。注册创建独立组织/项目，不能将新账号加入演示团队或授予系统管理员权限。尚未部署云端不阻塞本机双端联调。

同步必须区分两种证据：登录同一在线工作区读取共享服务端数据，以及本地离线数据上传、下载、冲突处理。前者通过不能声明后者已完成。迁移本地数据到账号前应由用户明确选择，不能自动上传全部本地资料。

| 业务后端 | Spring Boot、Java 21；40 个 Java 类引用 JDBC API | 复用业务服务；本地运行时由应用管理，不能要求用户手工运行脚本 |
| 数据库 | MySQL 专用驱动、61 个 Flyway 迁移；JSON_SEARCH、JSON CAST、upsert 等语法 | 先完成本地数据库兼容性验证，再确定引擎；不直接替换线上数据库或历史迁移 |
| Redis | 26 个 Java 类直接依赖 Redis；包含会话、任务流、心跳、租约、防重放 | 本地适配必须保留取消、超时、租约、幂等与重启恢复语义，不能只替换登录会话 |
| 对象存储 | 7 个 Java 类引用 MinioClient；附件及执行工件依赖对象存储 | 本地文件适配保留元数据、校验和、项目权限、流式下载及清理行为 |
| Runner | API、JMeter、Playwright、Appium 独立进程 | 本地模式仍隔离执行用户脚本和浏览器/设备命令；不能转移到控制面线程执行 |
| 登录 | `/auth/me`、Redis Session、组织项目权限共同决定页面入口 | 本地身份初始化必须限制在本地模式；企业模式不能被免登录逻辑影响 |
| 发布 | 当前 CI 原生构建 DMG universal / Windows x64 NSIS | 纳入本地后端、运行时、静态资源、架构匹配与首启测试，不能只产出旧壳的新包 |

统计来自基线工作区静态扫描。当前改造不代表这些依赖已解耦。

## 实施顺序与完成门槛

1. **固定兼容基线**：保留服务模式回归；梳理每个业务模块的页面、API、持久化和真实执行用例。
2. **验证本地基础设施**：验证实际数据库迁移与业务 SQL；建立持久化文件、会话、队列的本地适配。验证重启恢复和数据完整性，不能依赖测试内存替身宣称成功。
3. **应用生命周期**：本地服务自动启动/就绪检测/崩溃恢复/退出；避免端口冲突，使用独立数据目录；包含运行时，干净系统不用开发工具即可启动。
4. **身份与双模式**：根据用户选择实现个人工作区初始化、服务模式切换与会话隔离；升级不能删除旧服务器配置或覆盖已有数据。
5. **逐模块迁移**：功能测试 → 接口测试 → 接口自动化 → Mock → 性能 → Web UI → 移动端 → 报表/任务/设置/集成。当前模块完成修复和回归后再推进下一模块。
6. **备份与升级**：离线备份、恢复验证、数据库升级前备份和失败恢复；文件与数据库版本一致，秘钥不得明文混入导出。
7. **桌面发布验证**：Mac Intel/Apple Silicon、Windows x64 的干净环境首启；不预装开发工具、不运行现有 Docker 服务时验证核心闭环；内置/下载组件校验、签名和第三方分发要求独立核对。

以上是实施计划，不是完成声明。

## 已有功能保留原则

- 保留 `/api/v1` 业务接口及组织/项目边界，前端继续使用真实业务服务，不以返回空结果或模拟响应掩盖缺失能力。
- 企业部署继续采用现有 MySQL/Redis/MinIO 配置，新增本地模式默认不能改变企业配置、认证、安全策略或历史数据。
- 桌面服务默认只监听本机，并对桌面调用进行鉴权；不能因为“无需注册”就把无认证 API 暴露到局域网。
- 外部访问 Mock、远程 Webhook、团队协作等需要网络可达性。本地模式保留相应能力，但不能承诺未公开网络地址的电脑拥有公共互联网访问地址。
- 移动端仍需要实际设备/模拟器及其系统驱动；不能以“安装即用”为由把设备模拟测试计为真机通过。
- 不擅自发布公网服务、开通云资源、修改生产环境、清空数据库、提交 Git 或发布正式 Release。
