- 新增 `scripts/desktop/accept-cross-module.mjs`，将此前已通过的跨模块包级流程整理为可复用入口；使用共享离屏引导、显式应用／JMeter／浏览器缓存、独占摘要和独立账号服务。运行真实安装副本，退出后清除账号、数据库、截图、执行产物、进程及专属钥匙串。
- 修复 `build-install-baseline.mjs`、`build-install-fixtures.mjs` 的旧版数据库版本声明：从固定旧提交的迁移文件生成 V42 元数据，旧版夹具使用旧版声明，新版保留 V50。原先夹具会把候选的 V50 声明套在真实 V42 后端上；该问题在安装预检时发现，未放宽 smoke 中实际版本必须匹配的断言。修复后重新构建旧版并完整执行安装生命周期。

- 没有修改业务接口、数据库迁移或包内应用代码；以上验收脚本不进入安装包。最新 DMG 的生产输入与 GitHub main `7f01558` 一致，构建信息区分已提交的产品代码与未提交的验收改动。
