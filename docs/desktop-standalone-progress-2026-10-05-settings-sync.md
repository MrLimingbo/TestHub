# TestHub 安装即用：项目环境与普通参数离线双向同步

日期：2026-10-05。上一模块“任务登记离线双向同步”已获用户审核通过。本轮已完成，并于 2026-10-08 获用户审核通过；其余范围继续保留待办。

## 使用方式与范围

桌面“项目设置 → 项目环境”新增“项目配置同步”按钮，应用菜单也可打开。先连接账号服务并登录，再明确选择本地项目和账号项目，预览首次上传、下载、冲突及排除密钥数量，通过原生确认后绑定。默认不启用，每个模块本轮支持一组绑定；任务登记同步可独立保留另一组绑定。

按环境编码、参数键对应同一配置。同步环境名称、基础地址、说明及普通参数值；同名同内容复用，同名不同内容保留双方并要求选择。已有环境标识保持不变，接口用例和自动化场景的环境引用无需重新创建。`BASE_URL` 沿用环境服务生成，不能作为普通参数单独发送。

密钥名称仅用于阻止同名覆盖，不读取或复制密钥值。默认环境和启停状态按各端原有设置保留；新环境在目标启用，不改变已有默认环境。首次没有默认环境时沿用现有环境服务规则。普通参数值和基础地址会发送到所选服务，界面与确认框提醒将敏感值先改为密钥保存。

应用运行时每 30 秒检查两端。断网可继续在本地编辑；网络及绑定账号会话恢复后自动发送新建、修改并下载网页变更。支持立即同步、暂停、恢复和解除绑定。退出应用后不运行后台同步，会话失效需重新登录同一账号。

两端同时修改时显示双方完整配置供选择；确认时重新读取，内容已变或转为密钥则停止。参数键仅大小写不同时要求先统一名称，防止 H2 与 MySQL 排序规则造成不同匹配结果。密钥冲突、缺失环境依赖、删除或转为密钥均提示核对。删除操作不自动传播，也不自动重新创建；解除绑定保留两端业务资料。同名密钥冲突不会阻止其他合法配置继续同步。

本轮最多 100 个环境、1000 个普通参数、1000 个密钥定义；项目同步快照最多 3 MiB，请求和响应最多 4 MiB。派生 `BASE_URL` 不占普通参数额度。缺失但仍待核对的基线也计入本机容量，超过上限时停止发送，需核对资料或解除绑定重新预览。

测试资产、账号凭据、执行历史、文件、通知及其他模块仍不在本轮范围。原有一次性资料迁入入口继续保留。

## 一致性与数据保护

- `GET /api/v1/projects/{projectId}/project-settings/sync?expectedUserId=...` 返回最小配置投影、密钥阻挡键及目标修订摘要；`POST` 接收环境和普通参数的新建/更新批次。
- 双端检查账号和项目写入角色，沿用项目设置的 SYSTEM_ADMIN、ORG_ADMIN、PROJECT_ADMIN、TEST_LEAD 范围；普通只读成员及其他组织不能启用。POST 要求 CSRF，严格拒绝未知字段、重复标识/键、无效定义、缺失所属环境和超限正文。
- 所有配置写入与现有环境、参数、密钥和一次性迁移共用项目锁。目标摘要包含行标识、版本、参数内容及密钥元数据，连删除重建或默认环境变更也会使旧批次失效。任何冲突或审计失败均整批回滚，环境先于依赖参数写入。
- 提交前将原请求、UUID 和基线由系统安全存储加密并原子写入 `settings-sync.bin`；服务端保存回执。已提交但响应丢失后重启重发同一请求，返回原回执，不重复新增。409 清除已被整批拒绝的请求，再核对两端；网络失败保留待发送请求。
- HTTP 请求携带对应隔离会话，不跟随重定向，超时及大小有界，不回显内部报错。本机元数据权限为 0600，不保存密码、访问令牌或浏览器凭据。
- 复用任务同步的加密存储和原生 IPC/请求基础实现，保留既有 `task-sync.bin` 协议；两个业务同步引擎独立。原生窗口、页面和主框架均验证，远程页面只获得打开入口。
- 同步、迁移、执行设置保存和备份/恢复共享互斥保护。备份恢复确认后，在切换数据库前持久暂停两种旧绑定，要求重新预览；同步元数据位于工作区之外，不随备份复制到其他电脑。

新增 H2 `V21__project_settings_sync_receipt.sql`、MySQL `V78__project_settings_sync_receipt.sql`，不修改既有项目设置 API 或业务表。
