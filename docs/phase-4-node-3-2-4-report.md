# 阶段 4.3.2.4：Mock 分享与项目协作报告

## 交付范围

- Mock 服务增加可创建、复制、查看与撤销的只读分享链接；每个服务最多 20 条链接。
- 分享可设置 1 至 365 天有效期，或设置为永不过期；撤销后立即失效。
- 新增无需登录访问的分享说明页：`/mock/share/{shareKey}`，展示公开调用地址、服务状态、智能示例状态和规则概览。
- 项目成员继续依赖既有项目 RBAC 管理 Mock；创建与撤销分享链接要求项目写入角色，并记录审计事件。
- 新增公开接口 `GET /api/v1/mock-shares/{shareKey}`，用于分享页读取只读调用说明。

## 数据与安全边界

- 迁移 `V12__mock_shares.sql` 新增 `mock_share`，记录组织、项目与服务作用域、有效期、撤销时间和创建者。
- 分享内容仅包含规则名称、方法、路径、响应状态及条件摘要；不包含响应体、响应头、项目成员、环境变量或密钥。
- 链接格式不合法、已过期或已撤销时统一返回 404，不泄露所属项目或服务信息。
- 分享页仅为文档入口；不会授予配置、运行管理或项目读取权限。

## 验证记录

- `./mvnw -q -pl services/platform-api -Dtest=MockShareFlowTests test`：通过，覆盖创建、公开读取、安全字段排除和撤销后 404。
- `./mvnw -q -pl services/platform-api test`：通过，Flyway 验证 12 个迁移并完成完整后端回归。
- `npx pnpm@10.13.1 lint && npx pnpm@10.13.1 test && npx pnpm@10.13.1 build`：通过，包含匿名分享路由测试。
- 运行态校验：控制面重启后公开分享接口可访问；不存在链接返回 `404 REQUEST_REJECTED`，而非登录挑战。

## 用户预览步骤

1. 打开 `http://localhost:5173/mock`，选择一个 Mock 服务。
2. 在“协作与分享”区域点击“创建只读分享”，填写名称和有效期后创建。
3. 点击“复制链接”，在无登录会话的浏览器窗口打开该链接，确认只显示调用说明和规则摘要。
4. 回到管理页撤销该链接，再刷新分享页，确认其显示“分享链接不可用”。
