# 阶段 5 · 节点 5.11：租约校验与无敏感运行时索引

## 交付内容

- 可信 Runner 可校验已领取的短时租约，并取得该执行冻结的无敏感索引。
- 租约校验签名绑定任务、执行及租约 SHA-256 指纹；租约明文不进入签名负载、日志或响应。
- 索引只包含环境标识、场景版本、清单校验和及变量引用元数据（名称、来源、密钥标记）。
- 控制面再次验证 Runner 身份、任务投递状态、执行活动状态、截止时间和 Redis 哈希，防止跨任务、过期或伪造租约使用。
- Runner 协议支持构造校验请求，但当前禁用执行模式不会自动使用租约。

## 安全边界

- 索引不含变量值、环境密钥、请求 URL/头/体、Cookie、认证信息、脚本或步骤配置值。
- 租约不被回显；Redis 仍只保留其哈希和任务绑定元数据。
- 本节点没有配置值领取端点，不改变 `executionEnabled=false`，不触发网络请求或用户脚本。

## 验收建议

1. 打开接口自动化页，确认可信 Runner 的说明为“可校验无敏感变量来源索引”，且仍显示运行时配置关闭。
2. 确认未配置签名密钥的本地 Runner 仍不能校验租约。
3. 通过集成测试确认索引不回显租约，伪造租约或签名绑定不一致均返回 401。
