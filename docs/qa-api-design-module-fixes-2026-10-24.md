# 接口设计与导入：模块06缺陷修复

范围：用户授权修复 QA-DESIGN-001～009，回归后等待审核，不进入下一模块。原始190项测试定义、失败证据及详细复现步骤保留在 `output/qa-20261024/module-06-api-design/`；本次执行记录放在 `regression-r1/`。

| 缺陷 | 修复 |
| --- | --- |
| 001 | 定义创建、修订及版本创建的三个参数列表增加元素级非空校验。含 null 的项在控制器映射前返回400及字段错误；省略列表与空数组保持支持。 |
| 002 | 目录创建、改名、移动与删除先锁定所属项目行，串行检查和写入目录结构。同级重名包括根目录；采用 READ_COMMITTED，让等待锁的事务读取前一事务已提交的目录。与资料转移、同步现有项目锁兼容，无迁移或历史数据清理。 |
| 003 | OpenAPI入口校验声明类型和版本，只接收界面声明支持的3.0.x、3.1.x及Swagger字符串2.0；拒绝同时声明两种格式及非法版本。 |
| 004 | URL、请求头、请求体统一使用POSIX单引号引用，正确拼接内含单引号。补充特殊字符往返及只解析、不执行命令的语法检查。 |
| 005 | 单独记录显式方法与data选项。仅未声明方法且存在data时默认POST，显式方法不受选项顺序影响。 |
| 006～008 | 目录、接口、版本表单各自维护会话代次和保存状态。取消、重开、切项目、切身份及卸载使旧操作失效；CSRF等待后再次检查会话。旧写入已提交时可以刷新同项目列表，旧回调不得关闭新草稿或修改其字段、错误及spinner。版本快照固定打开时的基准内容。 |
| 009 | 四种格式导入共用会话检查。结果与窗口、项目、身份及输入内容绑定；文件读取另带序号，迟到读取不得覆盖新文件或手工输入。当前会话失败可重试。 |

新增后端回归位于 `ApiDesignFixesFlowTests.java`，覆盖入口校验、无副作用拒绝、四种目录并发、格式版本、七种方法两种顺序、特殊字符往返。新增前端回归位于 `src/test/apiDesignFixes.test.ts`，覆盖旧成功/失败、新保存状态、CSRF期间取消/切项目/卸载、失败重试、快照基准及文件乱序。
