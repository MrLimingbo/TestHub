# Mac 标准打包与完整回归（2026-10-19）

本模块继续 2026-10-16 r2 修复后的未完成工作：将显式 ad-hoc 资源封装固化到标准预览构建，并对新流程生成的最终 DMG 重跑实际功能及安装生命周期。用户要求全程后台、使用隔离数据、完成后清理，再按模块审核。2026-10-19 用户已审核通过，并授权先提交 GitHub main，再继续浏览器和 JMeter 首次下载验收。本模块没有替换本机已安装的 TestHub。

## 代码范围

- `apps/desktop/build/mac-preview.cjs`：继承全部基础构建钩子、应用身份和运行资源；显式本地资源封装，保留运行组件原始字节。
- `package:mac:preview`、`package:dir:mac:preview` 及根目录 `desktop:package:mac:preview`：统一入口；正式标签 Developer ID、公证与 Windows 策略保持原有门槛。
- `scripts/desktop/verify-mac-preview.mjs`：原生架构验证、完整资源封装、完整运行时校验及最终 DMG 内容一致性门槛，输出独占脱敏摘要。
- `.github/workflows/desktop-release.yml`：内部 Mac 目录包与预览 DMG 使用同一配置，上传预览安装器前验证最终映像。
- `scripts/desktop/build-install-fixtures.mjs`：旧版真实壳／后端安装夹具复用 Mac 预览封装，保留固定基线的来源验证。
- `apps/desktop/test/mac-preview.test.cjs`：覆盖资源封装缺失、身份错误、架构失败、运行时修改、最终映像替换、卸载失败保留挂载点及摘要失败关闭等回归。

首次最终包门槛被 `lipo` 参数顺序错误阻断，未进入应用启动。根据本机原生命令的实际用法，已将输入文件置于 `-verify_arch` 前，并将 Intel 架构名映射为 `x86_64`；同时修复正式验证器中相同的参数错误，不放宽其证书或公证策略。新增用真实原生可执行文件调用系统 `lipo` 的回归，避免只依赖替代命令测试；修正后重建最终安装器并重新验收。首轮失败摘要单独保留，未算作通过。
