1. Redis 6 的 RESP3 对象响应被忽略，任务与取消命令读出后不执行。兼容对象与数组两种返回形态。
2. 空步骤返回 500。对列表元素增加非空校验，返回 400。
3. 四种资产表单及执行表单提交失败仍关闭。使用提交前回调并返回明确成功/失败。
4. 新场景默认选中停用的浏览器配置。只选启用配置。
5. 场景变量接受数组等非对象值。提交前校验字符串值对象。
6. 切换项目后的迟到响应覆盖新项目资产。增加请求序号和项目校验，并关闭旧项目弹窗。
7. 报告不轮询、关闭后迟到响应恢复内容、失败后持续加载。统一报告请求生命周期和错误展示。
8. 文本断言不等待内容更新。按步骤超时轮询，延迟文本真实用例通过。
9. 导航跳转可访问未授权 Origin。每次执行创建本地出口代理，HTTP 请求和 HTTPS CONNECT 校验许可列表；浏览器上下文显式配置代理。Chromium、Firefox、WebKit 的未授权跳转均失败，目标服务收到的禁止路径请求增量均为 **0**。避免将 Chromium 的绕过参数传给 WebKit。
