# 阶段 4 · 节点 4.3.1.3.2.2：WebSocket 鉴权、订阅与自动重连

**状态：待产品验收**

## 本节点交付

- WebSocket 握手可解析选定环境的项目参数、加密环境密钥及动态值；解析结果仅用于本次连接，不写入会话历史、审计详情或浏览器持久化存储。
- 支持无认证、Bearer、Basic、API Key（请求头或查询参数）认证；对不安全的手工握手请求头继续拒绝处理。
- 支持最多 8 个合法、去重的子协议，并在会话摘要中展示服务端最终选定的子协议。
- 支持最多 12 条订阅文本帧（每条最多 32000 字符）。订阅帧只保留于当前内存会话，首次连接和每次自动重连成功后均按保存顺序自动发送。
- 支持有界自动重连：可选择启用，最多 5 次、间隔 100 至 10000 毫秒；显示 `RECONNECTING` 与重试进度。手动关闭会取消后续重连，旧连接的迟到回调不会污染新连接状态。
- WebSocket 连接目标仍限制为可公开访问的 `ws://` / `wss://` 地址；控制面不执行用户脚本。

## 当前兼容边界

- 本节点覆盖文本帧；二进制帧、Ping/Pong 控制帧可视化及复杂协议扩展留待后续节点。
- 自动重连采用固定、有界的重试次数与间隔；健康检查、指标告警和跨 Runner 分配不属于本节点。
- WebSocket 会话仍为用户与项目隔离的短期内存数据，不作为可复放的持久执行记录。
