# TestHub 安装即用：功能测试治理定义同步

日期：2026-10-10。上一模块“功能测试基础资料与计划同步”已获用户审核通过。本轮仅推进治理定义与标签编辑，尚未开始后续模块。实现、最终复验和阶段清理已完成，已于 2026-10-10 获用户审核通过。

## 使用与同步范围

资产治理页面和应用菜单新增“治理定义同步”。本地编辑保持可离线使用；连接账号服务并登录后，选择一组本地项目和账号项目，先预览，再通过默认取消的确认建立绑定。默认不上传，应用运行期间每 30 秒检查变更。支持立即同步、暂停、恢复、解除绑定、冲突选择和重启后的准确请求重放。

| 类型 | 匹配与同步内容 |
| --- | --- |
| 治理目录 | `GOVERNANCE` 范围的完整路径，重映射父 ID，保留排序 |
| 标签字典 | 按标签名称；名称与颜色，更新保持本端 ID 和创建信息 |
| 需求、用例、计划字段定义 | 按资产类型和不可变字段标识；字段名称、类型、必填、选项顺序 |

治理目录与标签/字段字典独立，现有系统没有字典挂目录关联，本轮没有新增此类关系。相同字段标识在三种资产类型中分别匹配。标签编辑使用原 ID，保留创建人、创建时间和现有资产绑定；字段更新同样保留原 ID、创建信息和不可变标识。

资产标签关联、字段填写值、需求/用例/计划内容、执行与历史、文件、缺陷和版本不在本模块同步范围。已有其他同步入口和显式迁移保持。删除不传播，也不自动重新创建；标签或目录改名按新名称/路径处理，旧名称缺失需手动核对。目录父级冲突或缺失暂停子目录，字典仍可独立处理。同名不同内容、两端同时修改需选择版本；确认期间再次变化会拒绝过期选择。含本端项目/文件链接的定义暂停同步，确认与预览会披露范围及两端资产标签关联的排除总数。

每类每项目最多 100 条，五类合计最多 500 条；目录最多 16 层，每字段最多 100 个不重复的有序选项，每选项最多 80 字符。快照及合并定义最多 3 MiB，POST 与原生响应最多 4 MiB。UTF-8 字节限制与字符/数量限制分别校验。原有 CRUD 的字段选项容量保持；超出持续同步范围的资料需要先核对，不能绕过限制自动发送。

## 一致性和持久化

- GET/POST `/api/v1/projects/{projectId}/functional/governance/sync`，协议版本 1、范围 `FUNCTIONAL_GOVERNANCE_SYNC`。准确账号、原写入角色、项目权限、CSRF 校验保持。
- 快照摘要包含本端 ID、字段更新时间和完整定义；标签没有更新时间，名称/颜色仍进入摘要。目录路径/排序亦进入摘要。
- 治理 CRUD、资产标签绑定、目录、显式迁移及同步共用项目锁。写入在 READ_COMMITTED 下等待锁后比较摘要；过期版本、唯一约束和审计失败整批回滚。
- 先加密持久保存准确请求与 UUID。项目/账号/requestKey 唯一回执支持已提交但响应丢失后的安全重放，保留后来修改且不重复创建。
- 新增 H2 V28 / MySQL V85 `functional_governance_sync_receipt`；原协议、表和旧同步文件格式保持。
- `functional-governance-sync.bin` 使用系统安全存储加密、原子写入和 0600 权限；不保存账号密码或会话令牌。复用可信 IPC、传输和加密存储，无新增产品依赖。
- 九种同步独立绑定，共用工作区操作互斥；备份恢复前全部持久暂停，并要求解除旧绑定、重新预览。退出 App 后不运行同步。
