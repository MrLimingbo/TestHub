# 阶段 3.3.2：缺陷关联与 Excel 导入导出

验收日期：2026-07-12

## 交付内容

- 新增项目内建缺陷：支持编号、标题、严重程度、状态、来源、外部链接与说明。
- 缺陷可关联当前项目的需求、测试用例和执行用例；关联、解除关联和删除缺陷均记录审计日志。
- 新增“缺陷与资产交换”页面，提供缺陷登记、资产关联和 Excel 操作入口。
- 支持需求与测试用例的真实 `.xlsx` 导出、空模板下载和导入。
- 导入采用全量预检：文件限定 5 MB、单批最多 500 行；目录、编号、状态、优先级、关联需求和必填列均会逐行校验。任一错误均不会部分写入，并在页面返回行号和原因。
- Excel 能力采用 Apache POI 5.5.1；该版本为项目官方公布的稳定版本，组件采用 Apache License 2.0。[Apache POI 发布说明](https://poi.apache.org/download.cgi)

## 数据与安全边界

- Flyway `V5__functional_defects.sql` 创建 `functional_defect` 和 `functional_defect_link`。
- 缺陷、关联和资产交换接口均校验组织/项目范围，并沿用项目级写权限。
- Excel 只接受工作簿格式；输入不合格时不触发数据库写入，避免半导入状态。

## 浏览器验收路径

1. 登录后访问 `/functional/delivery`。
2. 新建缺陷并从“追溯关联”中关联一条需求或测试用例。
3. 在“资产导入与导出”选择需求或测试用例，分别点击“导出当前数据”和“下载模板”。
4. 选择模板文件并可尝试导入：正确数据应显示成功；故意写错目录或编号应显示精确行号且不写入任何数据。
5. 返回“功能测试”，确认“缺陷与交换”入口可访问。
