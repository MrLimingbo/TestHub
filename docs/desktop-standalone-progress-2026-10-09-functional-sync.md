# TestHub 安装即用：功能测试基础资料与计划离线双向同步

日期：2026-10-09。上一模块“移动端配置同步”已获用户审核通过。本模块实现与验证已完成，阶段清理完成，已于 2026-10-10 获用户审核通过，继续治理定义同步模块。

## 使用与范围

功能测试页面和应用菜单新增“功能资料同步”入口。连接账号服务并登录后，选择一组本地项目和账号项目，先预览上传、下载、冲突及排除的历史/文件，再通过默认取消的确认建立绑定。默认不上传。应用运行时每 30 秒检查新建和修改；断网可继续本地编辑，会话有效且联网后自动重试。支持立即同步、暂停、恢复、解除绑定和选择冲突版本。

| 类型 | 同步内容及匹配方式 |
| --- | --- |
| 需求、用例、计划目录 | 按类型及完整目录路径匹配，重映射父目录，保留排序 |
| 需求 | 按需求编号匹配；目录、标题、优先级、资料状态、说明 |
| 用例 | 按用例编号匹配；目录、可选需求引用、标题、优先级、资料状态、原八种用例类型、前置条件、步骤、预期结果 |
| 测试计划 | 按计划编号匹配；可选目录、名称、资料状态、说明、有序用例关联 |

引用使用路径及编号传输，写入时映射为目标端自己的 ID。更新保留资产 ID、创建人员和创建时间；已有治理关联、执行批次和步骤快照保留各端。同编号改标题属于更新。同步计划定义不会创建执行或改写历史。目录路径大小写差异需手动统一；同名不同内容或两端均修改需选择，确认期间再次变化则拒绝过期选择。父目录、需求或用例存在冲突/缺失时暂停依赖资料，其余可独立同步的资料继续。

正文含 `/api/v1/projects/` 或对应编码链接时，相关资料暂停同步，避免复制本端文件/项目 ID；即使两端链接相同，也不会建立可自动覆盖的基线。附件、人员、标签、自定义字段、缺陷、版本和执行历史不在本轮持续同步范围，继续使用已有显式迁移。确认会披露所有同步正文将发送到所选账号服务。删除不传播，也不自动重建；改名按新路径/编号处理，原名称缺失需核对。

每类每项目最多 100 条，共六类最多 600 条；目录最多 16 层，计划最多 100 个不重复的有序用例关联，单个正文字段最多 20,000 字符。快照及合并定义最多 3 MiB，POST/原生响应最多 4 MiB。合并数量包含基线中待核对的缺失资料。预览的排除数量统计两端全部项目执行批次及项目文件。

## 一致性与保护

- GET/POST `/api/v1/projects/{projectId}/functional/sync`，版本 1、范围 `FUNCTIONAL_SYNC`；准确账号、原写入角色、项目权限和 CSRF 校验继续生效。
- 校验字段规范化、编号、完整引用、重复操作、数量及字节界限；未知字段、尾随 JSON 和空目录路径返回 400。声明长度和分块超限返回 413。
- 一致读快照摘要包含本端资产 ID、更新时间及完整定义；目录无更新时间，排序和完整路径也进入摘要。
- 原 CRUD、显式迁移、同步及创建执行读取定义使用共同项目锁。写入在 READ_COMMITTED 下等待锁后比较最新摘要，过期版本、数据库唯一约束或审计失败整批回滚。
- 先持久保存准确请求及 UUID；项目/账号/requestKey 唯一回执支持响应丢失后的准确重放，不重复创建、不修改时间或覆盖后来的编辑。
- `functional-sync.bin` 使用系统安全存储加密、原子写入和 0600 权限，位于工作区之外；不保存账号密码或登录令牌。复用已有可信 IPC、HTTP 和加密存储，无新增产品依赖。
- 八种同步独立绑定，与备份/迁移共用操作互斥；恢复前全部持久暂停并要求解除旧绑定、重新预览。退出 App 后不运行同步。

新增 H2 V27 / MySQL V84 `functional_sync_receipt`。原编辑、显式迁移、执行与报告接口保持，七份旧同步文件格式保持。
