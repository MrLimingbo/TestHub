# 插件与运维：本机管理、签名原文、配置保护和运行投影

状态：通知与集成模块于 2026-10-05 获用户审核通过。本轮完成插件/运维代码与隔离回归、源码和最终内部 Mac arm64 包真实流程，本模块于 2026-10-05 获用户审核通过，继续跨模块真实执行与统一列表模块。

## 范围与保留行为

- 插件中心仍是可信签名清单的登记、版本与启停管理，控制面不会下载、加载或执行第三方插件代码。企业适配器仍校验地址与字段、加密保存配置；实际目录同步、第三方通知、缺陷同步需要对应独立工作进程。本轮保留这些现有能力，不将配置保存误报为实际接入完成。
- 全局签名信任、插件登记与适配器配置由当前服务的系统管理员管理，本机拥有者保留原 SYSTEM_ADMIN 能力。复用已有管理能力接口，普通注册账号保留插件/适配器脱敏登记信息的既有读取权限，隐藏管理操作且不挂载管理表单、不请求签名密钥。后端原写权限保持；直接调用管理接口仍为 403。
- 插件页权限或列表读取失败显示错误及重试，清除旧列表；签名密钥读取失败单独显示，不能把网络失败解释为没有管理权限。读取序号阻止旧响应覆盖新列表，卸载后的响应不更新页面。
- 签名密钥、插件安装与适配器保存使用等待式弹窗钩子，失败保留输入，重复提交去重。在等待 CSRF 前捕获原目标及字段并序列化；取消或替换表单使旧回调失效。成功、取消、离开页面清理签名、清单及适配器配置草稿，已有凭据不回填。
- 插件启停、签名信任启用/撤销与适配器删除均增加或保留明确确认，取消不写入。撤销公钥只阻止新安装，已登记插件保持原状态，沿用既有契约。新装与升级均停用，原管理员再明确启用。
- 插件清单签名和校验和改为覆盖提交的原始字符，包括首尾空白；修复此前服务端 trim 导致已正确签名的清单失败。版本仍要求长度不超过 48 的 MAJOR.MINOR.PATCH，使用 BigInteger 比较合法的大版本号，避免升级时 Integer 溢出；同版本或回退仍返回 409。
- 适配器编辑 JSON 留空发送 `configuration=null`，保留同类型的现有加密配置，可修改名称、地址及启用标记。填写则校验完整配置并整体替换，不合并空白字段；新建、变更类型仍须完整配置。事务内读取原行加锁，避免元数据编辑覆盖另一个窗口的新凭据。列表仍仅返回字段名，审计不记录凭据。
- 上述配置是服务级管理信息，不自动复制本地信任、插件权限或凭据到注册账号；账号服务的管理员独立配置。普通账号在桌面及网页读取同一服务的登记信息，不能借迁移获得系统管理权限。

## 运维差异

- 运维接口保留原概况字段，新增 `runtimeMode: DESKTOP | SERVER`，来自真实后端运行 profile。依赖仍通过已有数据库、持久队列/Redis 与文件/对象存储适配进行检查；页面展示实际标签，不再写死 MySQL、Redis、MinIO。
- DESKTOP 使用本机回环会话说明、原生生命周期与安装包发行待验收项，去掉本机不使用的容器/Helm 控制说明；SERVER 保留原服务端部署控制。`UP` 仍仅代表基础依赖正常，容量演练、备份产物、签名公证及跨平台发行不会据此自动判定通过。
- 本地备份说明指向现有桌面加密备份入口，恢复仍由原生确认后离线执行；接口没有读取备份产物，不能声称已存在合格备份。持久队列按各模块规则恢复，结果不明的通知需核对接收端，避免“全部消息自动重投”的误导。
- 运维页先读取管理能力；普通账号显示权限说明且不请求概况，后端概况仍拒绝访问。刷新先清除旧健康结果，错误可重试，过期或卸载后的响应被忽略。待处理计数包含失败依赖、实际安全/恢复/容量条目及迁移异常，不重复用容量汇总代替多个条目。
- 原生加密备份按钮只在本机桌面显示；账号网页不会展示无法工作的桌面入口。页面没有新增生产变更、凭据轮换、恢复或发行操作。

本轮没有新增数据库迁移，H2 保持 V19、MySQL 保持 V76。后端构建变更仍触发原有工作区升级前快照机制。
