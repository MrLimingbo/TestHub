# 阶段 5 · 节点 23：场景运行配置集与执行覆盖

## 交付内容

- 新增项目级运行配置集 `api_automation_execution_profile`，由 Flyway `V26` 管理；每个配置集包含名称、执行环境、非敏感变量与乐观锁版本。
- 场景提交接口支持可选 `executionProfileId` 和一次性 `overrides`。执行记录保留配置集 ID/版本，便于追溯；最终变量值仅进入内部运行时快照。
- 变量优先级为：项目参数、场景变量、运行配置集、数据集行、本次执行覆盖、环境密钥、Runner 本地提取变量。
- 运行配置集和一次性覆盖均不能覆盖当前环境密钥；密钥只保留名称，既不会解密也不会进入浏览器、执行清单、日志、报告或 Outbox。
- 执行清单和 Runner runtime artifact 使用配置集选择的环境及冻结后的最终变量；后续编辑配置集不影响已创建任务。
- Web 新增“场景运行配置集”管理区与“提交场景执行”弹窗，可选择配置集、填写 JSON 一次性覆盖变量及执行超时。

## 验证

- 新增 `ApiAutomationExecutionProfileFlowTests`，覆盖配置集环境生效、一次性覆盖优先级、执行记录关联、脱敏执行清单与运行时摘要。
- 使用 MySQL 8.4 本地开发库验证 Flyway 已迁移至版本 26。

## 运行边界

- 配置集变量只能是字符串且最多 100 项；不得用于保存 Token、密码或私钥。
- 数据集批量执行仍沿用数据集变量链路，不接受运行配置集与本次覆盖，避免单次配置被隐式复制到大量任务。
