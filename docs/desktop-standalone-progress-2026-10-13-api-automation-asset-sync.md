# 接口自动化基础资料持续双向同步（已审核通过）

本模块新增 `API_AUTOMATION_ASSET_SYNC / 1`，在接口自动化页或原生菜单打开绑定窗口，预览并确认本地项目与账号项目后，持续同步公共步骤当前内容、完整数据集和执行配置集。按类型及名称对应；每类最多 100 条，总计最多 300 条、8 MiB。步骤配置、数据集的全部行及配置变量会发送到绑定服务，绑定确认明确展示这一范围。

用户选择“保留历史引用，追加新版本”。已有公共步骤更新通过原业务服务追加修订，原 ID、创建信息和历史修订保留，固定旧版本的场景引用不会漂移。新公共步骤复制当前内容为目标端 v1，旧修订的跨端映射留给下一场景模块。执行配置集更新递增目标版本号；后续使用它的执行采用新变量，已经创建的执行快照保留。数据集更新保留目标 ID，并同步全部规范化行与原始格式。

数据集来源文件和正文下载链接复用已获审核的项目文件对应关系，只映射已配对且内容完好的文件；未配对、失效、删除或跨项目链接暂停涉及资料。配置集目标环境须存在并启用，缺失或停用时暂停配置集，无关资料继续同步。双端同时编辑和首次同名不同内容要求选择保留一端；删除、改名和同名重建暂停核对，不自动删除或重建。场景、旧修订、定时任务、Webhook、执行历史不在本协议范围，同步自身不创建执行任务。

后端新增 H2 V39／MySQL V96 幂等回执表，具备账号与权限检查、CSRF、项目锁、修订校验、整批事务及稳定请求回执。前置请求限制为 10 MiB，包含 chunked 请求。桌面同步基线与待确认请求加密保存；断线重试使用原请求键，避免公共步骤再次追加修订。工作区恢复后此绑定持久暂停，并要求解除后重新预览。
