## 受控超时定位

另起一轮 V50→V57，V50 正常退出耗时 0.798 秒。完成迁移和数据核对后，对 V57 隔离应用的 Playwright Runner、API Runner 和后端进程发送 `SIGSTOP`，使三个进程都无法响应正常停机。测试在 30 秒处记录超时，并留出短暂观测时间，捕获应用后续的实际退出。

| 进程 | 请求关闭标准输入 | 应用发送 `SIGKILL` 的时间 | 等待 |
| --- | ---: | ---: | ---: |
| Playwright Runner | 0.002 秒 | 10.004 秒 | 10.002 秒 |
| API Runner | 10.025 秒 | 20.027 秒 | 10.002 秒 |
| 本地 Java 后端 | 20.040 秒 | 30.040 秒 | 10.001 秒 |

Electron 在 **0.001 秒**进入运行时停机，**30.085 秒**完成停机，**30.130 秒**退出并关闭输出管道。原启动器从调试器断开后开始算 30 秒，这次按同一口径耗时 **30.129 秒**。同配置的正常对照在 **0.829 秒**退出。应用在 `before-quit` 等待本地运行时关闭，而运行时逐个关停子进程，每个没有响应的进程最多等待约 10 秒后才强制终止并处理下一个。三个等待串行叠加，解释了这次受控超时。 [退出入口](../../../../apps/desktop/app/src/main.cjs#L1521) · [串行停机](../../../../apps/desktop/app/src/local-runtime.cjs#L280) · [启动器阈值](../../../../scripts/desktop/offscreen-mac-qa.mjs#L93)
