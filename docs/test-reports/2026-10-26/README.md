## 2. 实测覆盖

覆盖模块：账号与认证、项目/成员/PAT 权限、工作台、功能需求/用例/计划/执行/缺陷、接口设计及版本发布/导入导出、接口调试、API 自动化、性能计划、UI 自动化、移动自动化资产、Mock、环境参数与密钥、版本、文件、通知模板、任务中心、报告、插件、运维、系统设置和审计。

重点验证包括：

- 登录、错误密码、CSRF、匿名访问拒绝、跨账号项目隔离、只读成员写入拒绝、PAT 只读与撤销后失效、成员移除后即时撤权。
- 需求/用例/计划/执行链路、需求关联、步骤与整条用例结果约束、缺陷关联、接口版本发布后保护、非法文档拒绝及导出下载。
- API 自动化场景版本及旧版本冲突，浏览器/移动/性能资产的配置、必填/枚举/边界校验；不会把资产配置成功等同于真实设备执行成功。
- Mock 公开路由命中、方法不匹配、禁用后不可访问及重新启用。
- 中文文件上传、2 MiB 上传、下载 SHA-256 一致、跨账号下载拒绝、超过 20 MiB 返回 413。
- **28 个已认证页面实际渲染与截图**、匿名深链登录跳转，以及 **6 条新增真实表单/页面交互**：空字段校验、错误/正确密码登录、需求搜索空态、需求编辑保存并刷新持久化、上传文件页面可见。
- 页面使用隐藏/offscreen **Electron Chromium** 执行，不是单纯请求 HTML，也不是完整桌面发行包验收。页面导航通过不代表该页全部操作都已人工逐项验收。
- 深度业务分支另由 2,311 条既有回归补充，逐条名称及结果见 CSV。

模块计数与逐条结果见 [coverage.md](coverage.md)、[results.csv](results.csv)。

## 3. 发现的缺陷

| 编号 | 建议级别 | 问题 | 验证方式 |
| --- | --- | --- | --- |
| BUG-001 | 高 / P1 | 非执行 Runner 收到取消后确认取消，任务所有者未感知 | 双实例内存探针 + 共享消费组源码核查；真实 Redis 双节点集成仍待验 |
| BUG-002 | 中 / P2 | `Content-Type: text/plain` 请求 JSON 接口，返回 500 而非 415 | 真实 HTTP 首轮与复测一致 |
| BUG-003 | 中 / P2 | 已认证访问不存在的 API 路径，返回 500 而非 404 | 真实 HTTP 验证 |

**详细前置条件、操作步骤、预期/实际结果、定位线索和证据见 [bugs.md](bugs.md)。**

BUG-002、BUG-003 可能属于同一公共异常映射根因，按两个独立失败行为登记，开发可以合并修复任务。BUG-001 不夸大为真实集群端到端已验证的外部副作用事实。

## 5. 阻塞与限制

本轮 7 条阻塞项：

1. 生产同构 MySQL / Redis / MinIO 全链路：未提供专属依赖环境。
2. Android 真机执行及产物回传：未提供专属设备与 Appium。
3. iOS 真机执行及权限弹窗：未提供设备、签名应用及 WebDriverAgent。
4. Windows 安装、升级、卸载：当前主机为 macOS。
5. 最终签名发行包安装与升级：未指定发行物，未替换用户当前安装。
6. 生产容量、长稳与极限负载：未给容量目标、专用发压机及被测目标。
7. 两台真实设备断网重连与跨端同步：仅单机，不能冒充双机实测。

另外，既有回归中有前述 2 条主动跳过项。报告不能据其他回归通过将它们视为通过。
