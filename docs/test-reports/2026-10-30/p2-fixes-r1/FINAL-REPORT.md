## 修复内容

- **D01 / OBS-03B-E001**：普通参数、密钥保存前校验同项目环境定义，未定义返回 400；旧孤立行保持可见、只读和显式删除入口，不自动补定义或迁移删除。
- **D03-CFG / OBS-03B-E005**：界面允许有权用户维护停用环境配置，标记不可执行，与 API 一致；P1 停用环境的执行保护保持。
- **D09 / OBS-06-E006**：OpenAPI/Postman/HAR 保留合法单响应状态码，100–599 整数及兼容数字串；缺失/null/空元数据默认 200；浮点、越界、非法和损坏值受控 400。三格式单响应闭环补验，不扩多响应。
- **D10 / OBS-06-E012**：新增服务端预检和原子复制接口，目录/当前接口版本/审计/持久回执同事务；同项目、同父级，200 项上限；源摘要变化 409；同 Key 同载荷重放、异载荷 409、新 Key 明确新复制。真实 QA JAR 重启后原回执仍有效。界面断线保留 Key，切项目和离开后返回均阻止原操作误提交。
- **D17 / OBS-10-E010、OBS-11-E020、OBS-14-E025**：性能 queryParameters、Web 场景 variables、企业适配器 configuration 在 trim 冲突覆盖前返回 400；无失败落库或重新加密。保留原大小写、独立对象、合法 URL 重复查询和省略配置保留原密文的行为。
- **D22 / OBS-13-E020**：复用 config_version，对外返回 version；原生编辑必须带 expectedVersion，缺失/null 428、旧版本 409、非法类型/范围 400、成功加一，0 为有效版本。界面保留草稿，主动读取最新配置并另行保存；运行元数据不增加配置版本。原同步 revision 和权限保护保持。
