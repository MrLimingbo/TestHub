# D06 详细复现与回归对照

本轮只处理OBS-03D-E007一项P3观察。所有账号、字段及令牌均在隔离测试库中准备；不查询或修改用户实际账号。

## 百分号与下划线误匹配

1. 以隔离系统管理员进入账号管理。
2. 分别在账号、姓名、邮箱、电话中各创建一条含字面百分号的记录；另保留管理员和一条不含百分号的普通记录，共6条未删除记录。
3. 在搜索框输入单个 `%`，或GET /api/v1/accounts传递keyword为字面百分号（URL编码%25）。
4. 修复前B02的total实际为6，期望4，说明把百分号当作通配符；修复后列表及total仅包含四条字面命中记录。
5. 对下划线重复同一矩阵，keyword为 `_`。修复前B03实际6、期望4；修复后仅字面下划线命中，不匹配任意一字符。

## 反斜杠漏匹配与组合字符

1. 在四个搜索字段各准备含字面反斜杠的隔离记录。
2. 搜索单个反斜杠（URL编码%5C）。修复前B04实际total为0、期望4；修复后命中四条。
3. 搜索末尾反斜杠、连续百分号/下划线/反斜杠，以及感叹号和混合串。应只命中字面子串，不吞字符或报SQL错误。
4. 修复前B05第一组连续百分号矩阵实际5、期望4；B11反斜杠/百分号/下划线/感叹号组合实际0、期望4。失败断言之后的同方法输入变体当时未执行，不推算为全部已复现。

## 分页、权限及字段安全

1. 创建13条含同一特殊字面子串的记录，固定创建时间，让账号作为次级排序；按每页5条读取，应为5/5/3，下一页空且total为13。
2. 列表/count、空值/空白、停用可见、软删除过滤及null电话均按原规则；原分页上下限归一化保持。
3. 引号及SQL片段继续作为绑定参数，可字面命中但不扩大结果，不改变账号或业务审计。原查询已经参数化，本观察不是已确认SQL注入。
4. 匿名401、普通用户403、真实有效项目Bearer PAT即便属于系统管理员也403。响应保留原公开字段，不返回passwordHash/securityVersion。
5. 前端实际输入/搜索按钮、翻页、清空和错误重试保留字面keyword；旧响应不覆盖新行及总数。

MySQL最终使用在连接建立时分别配置普通与NO_BACKSLASH_ESCAPES的自有连接，参数回显、同一生产仓库的四列列表及count均通过；每个模式的夹具在本连接rollback后关闭，不改变全局配置。具体结果见[MySQL结果](backend-mysql.json)。

首轮MySQL 56项中55通过，B11中途SET会话模式后期望4、实际0。补充诊断发现同一连接中参数回显已不同于输入，与Connector/J缓存sql_mode的编码状态不一致相符。按官方sessionVariables在新连接中配置后，两种模式的原4条命中断言均通过，最终56/56。生产修复没有为此追加变更；原失败保存在[首轮MySQL摘要](MYSQL-INITIAL-RESULTS.json)，在用连接中途切换sql_mode不作本轮支持承诺。

有效修复前H2红测12个方法中7通过、5失败、0错误；5个失败是同一观察的不同切面，不登记为5个新产品Bug。前端原有URLSearchParams正确，未保存独立失败红测，专项回归4个通过。
