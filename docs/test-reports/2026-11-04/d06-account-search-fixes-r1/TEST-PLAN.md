# D06 账号搜索：先行用例

日期2026-11-04，依据D06-A、OBS-03D-E007、D06-AC01至04。仅处理GET /api/v1/accounts的keyword：四列按原trim/小写与排序规则做字面子串匹配；百分号、下划线和反斜杠不是用户通配语法。列表与count一致，空搜索、分页及权限保持，不扩大到其他模块搜索。

先设计16个方法：正例7、反例7、混合2，后端12、Vue/Arco4。字段/字符矩阵与H2/MySQL重跑不增加方法数。以下是设计预期，尚非通过结果。
