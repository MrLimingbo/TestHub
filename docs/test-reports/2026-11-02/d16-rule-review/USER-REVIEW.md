|D16-OLD 生效和存量|批准后对本矩阵字段的写入/导入/同步/新入队同时应用；旧记录可读，不批量重写。|先盘点旧客户端，另定兼容白名单和生效时间，再决定实施。|

整数判定A并不允许取整：原始1.0000000000000001必须拒绝，不能先转double变成1再放过。原始NaN/Infinity、超范围/溢出、布尔和容器均不能冒充合法数值。性能错误率仍是0..100、最多两位的小数，不改成整数。
