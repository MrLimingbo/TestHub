# 10项批准候选修复与后台回归计划

日期：2026-10-29。仅10项DIRECT获批；35项RULE、2项SPEC、12项环境阻塞不执行；独立升级关闭超时风险保持UNCONFIRMED_RETAINED。

## 执行顺序

1. 根据批准边界补行为回归用例，先执行原代码复现。
2. 逐项最小修改，验证新用例及相关历史保护用例。
3. 完整前端测试、lint、类型检查及构建；仅在新增失败或变更后重跑相关检查。
4. 使用现有浏览器运行时进行无窗口UI回归，使用隔离HTTP夹具注入失败、延迟与权限；不将替身结果标成真实服务或设备验收。
5. 复核增量代码、未授权项状态、测试进程和临时文件清理；生成报告等待审核。
