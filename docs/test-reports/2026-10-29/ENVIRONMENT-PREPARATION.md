## ENV-ANDROID · Android设备或模拟器

优先级：P1（发行包含移动执行时）；用例：12/D001, 12/D003, 12/D004；前置：G00范围与资源确认。

**补齐清单**

- [ ] 独占或授权的Android设备/模拟器，记录系统版本、ABI、设备授权状态和QA标识。
- [ ] 可用Android SDK/platform-tools、adb及兼容的Appium服务和Android驱动；外部版本先形成矩阵，不自动用最新版。
- [ ] 自有测试APK或已授权预装App、包名/入口、稳定测试元素、测试账号和可恢复测试数据。
- [ ] TestHub、Runner与Appium之间的批准网络可达，原有目标约束和TLS不放宽。

**需要你提供/确认**

- 是否将Android执行纳入本次发行；使用真机、模拟器或两者。
- 可用设备/远端测试资源与授权范围、App资料；不在文档中提供密码。

**审核后预检**：审核后先只读确认工具、驱动、设备授权、网络与应用状态，再决定缺项安装；本轮未探测当前设备。

**验收内容**：D001实际完成LAUNCH、TAP、INPUT、ASSERT_VISIBLE、ASSERT_TEXT、WAIT、SCREENSHOT；D003/D004按获批平台执行真实断开/授权错误、超时/取消及会话释放。

**关闭阻塞所需证据**

- 平台/工具/驱动版本和受控设备标识
- 真实Appium会话与步骤结果
- 实际PNG字节/类型/SHA及报告关联
- 故障后新会话恢复、已取消后无后续步骤、无自有会话残留

**清理边界**：只清理自有会话、测试数据和经授权的QA应用；不重置个人设备或卸载用户App。


## ENV-IOS · iOS真机或模拟器

优先级：P1（发行包含移动执行时）；用例：12/D002, 12/D003, 12/D004；前置：G00范围与资源确认。

**补齐清单**

- [ ] 可用macOS测试主机、Xcode/命令行工具及simctl或已授权真机。
- [ ] 兼容的Appium服务与iOS驱动，真机所需签名、设备授权和自动化辅助组件已准备。
- [ ] 自有测试App的bundleId和平台适配安装产物；真机与模拟器包不可混用，当前接口不支持的产物形式不得临时扩展后冒充验收。
- [ ] 隔离测试账号、可恢复数据和批准网络。

**需要你提供/确认**

- iOS真机、模拟器或两者的验收范围及可用资源。
- 现有App、签名/授权配置入口；无需发送私钥或凭据正文。

**审核后预检**：审核后只读核验Xcode、simctl/设备、驱动和App匹配；缺少条件时保持阻塞。

**验收内容**：D002实际七步与PNG；D003/D004在iOS范围验证断开/授权、超时/取消及设备会话释放。

**关闭阻塞所需证据**

- 原生系统/驱动/设备版本
- 真实iOS会话及步骤与PNG摘要
- 授权/断开真实错误和恢复
- 取消/超时后的会话释放结果

**清理边界**：只回收自有会话及授权QA数据；不修改用户设备信任、生产签名或个人应用。

## ENV-INTEL · Intel Mac原生环境

优先级：P1（发行包含macOS x64时）；用例：15/X001, 16/Z001；前置：G00范围与资源确认。

**补齐清单**

- [ ] 可用自有Intel Mac或原生Intel执行环境，不能由arm64/Rosetta替代。
- [ ] 原生Java21、符合仓库要求的Node和锁定依赖、原生x64运行时及完整许可/库存。
- [ ] 同一批准源码输入、独占缓存和新QA工作区；复用现有构建/离屏验收脚本。

**需要你提供/确认**

- 是否支持macOS x64及目标系统范围。
- 可用主机或CI权限、批准的源码ref和执行窗口；不自动创建标签或Release。

**审核后预检**：先确认实际CPU架构和运行组件依赖；CI标签存在于仓库不等于资源当前可用。

**验收内容**：15/X001、16/Z001原生首启/重启、身份与记录保持、备份恢复及相应包级链路；正式签名另走签名组。

**关闭阻塞所需证据**

- OS/架构、源码和后端/ASAR/运行时摘要
- 严格资源封装与库存
- 真实包离屏运行及重启持久化
- 自有进程/数据清理

**清理边界**：保留脱敏摘要及需要的当前运行时，删除自有测试应用和临时工作区；不替换用户安装。


## ENV-WINDOWS · Windows x64原生环境

优先级：P1（发行包含Windows时）；用例：15/X002, 16/Z002；前置：G00范围与资源确认。

**补齐清单**

- [ ] 独占干净Windows x64主机/虚拟机或授权原生CI，能够执行真实NSIS安装与PowerShell。
- [ ] 原生Java21、受支持Node、锁定Electron/依赖及完整win32-x64运行时。
- [ ] 隔离安装目录、用户配置、注册项和快捷方式范围，执行前确认无既有用户实例/数据。
- [ ] 自有恢复/升级夹具及需要的组件缓存，网络和摘要校验保持。

**需要你提供/确认**

- Windows目标版本、预览或正式发行范围。
- 现有主机/CI权限及专属快照；安装和清理范围。

**审核后预检**：审核后只读核验架构、工具、权限、空安装状态和目标路径，再按批准范围安装。

**验收内容**：15/X002、16/Z002实际默认目录首启、重启、PowerShell、恢复与跨系统工作区验证；依赖符号链接的平台跳过项继续单列。

**关闭阻塞所需证据**

- 原生架构、PE/运行时/安装器摘要
- 真实安装、目录、快捷方式和卸载注册项
- 重启/恢复后的身份、记录、字节与权限
- 若正式发行则真实Authenticode证据另关联

**清理边界**：只回滚自有安装、QA注册项/快捷方式和工作区；不卸载既有TestHub或清理用户配置。

- [ ] Windows若纳入正式发行，准备相应代码签名和时间戳条件；与Windows原生证据分别留存。

**审核后预检**：确认已有配置和工具是否满足仓库签名门槛；发现门槛路径未具备时另列阻塞，不使用预览绕过。

**关闭阻塞所需证据**

**清理边界**：仅清理自有临时签名副本和日志；保留安全配置入口，不导出私钥/原始系统凭据。


## ENV-CLEAN-INSTALL · 干净机器Finder/Gatekeeper首启

优先级：P1（正式对外分发前）；用例：15/X003, 16/Z004；前置：ENV-SIGNING。

**补齐清单**

- [ ] 独占干净原生macOS测试会话及已核验的最终发行DMG，保留正常隔离/Gatekeeper链路。
- [ ] 允许在该专属会话中进行真实可见Finder首启及录证；不使用用户当前前台桌面。
- [ ] 确认空默认应用/数据目录、授权测试账号和可回滚基线。
- [ ] 签名/公证通过在先；不能禁用Gatekeeper或移除隔离标记来伪装通过。

**需要你提供/确认**

- 可用的独占原生GUI会话、目标系统与安装范围。
- 批准专属测试会话中的真实可见首启；若要求绝对全程离屏，这两项继续阻塞。

**审核后预检**：只读确认干净状态、最终包摘要和前置签名结果，未满足不执行安装。

**验收内容**：15/X003、16/Z004真实Finder/Gatekeeper安装首启、默认路径、退出/重启及数据保持；离屏smoke不能代替。

**关闭阻塞所需证据**

- 干净状态、系统版本及最终DMG摘要
- 真实Gatekeeper和Finder首启记录
- 默认目录及重启持久化
- 自有安装与数据回滚

**清理边界**：只回滚专属测试环境，不替换用户已有安装或接管个人工作区。

## 状态流转与保留边界

有资源或安装成功不等于用例通过。按“待审核→只读预检→缺项准备→原生真实执行→证据复核”推进；未通过的原用例继续阻塞，失败若登记Bug需另给复现步骤。
正式分发前需完成对应平台签名、公证/Authenticode及实际安装链路；不得手工改distributionReady、禁用Gatekeeper、移除隔离标记或以跨架构模拟代替原生验收。
移动端设备创建、Appium协议模拟和伪造PNG不构成真机成功；截图证据使用自有测试App/数据。后台/离屏约束仍适用，真实Finder首启仅在获批专属可见会话中进行。
