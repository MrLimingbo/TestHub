# 质量报告与任务 D16 测试设计

范围：已批准的 `OBS-13-E018` 及 D16 A 组合；先设计后执行。仅针对任务 progress 和质量报告周期，不改变其他字段契约。沿用既有权限、版本、事务、任务状态机与调度规则。

|编号|测试点|预期|
|---|---|---|
|QT01|任务更新 progress 0、100、中间值、10.0、1e1|精确整数成功，状态机规则保持|
|QT02|任务更新缺失/null、小数和极小小数、负数/101、溢出、数字字符串/布尔/容器|400；原记录、版本和成功审计不变|
|QT03|QUEUED、SUCCEEDED 分别提交合法和非法 progress|合法值先验证后分别归0和100；非法值不能借归一化绕过|
|QT04|任务导入与同步中的 progress：等值数字、类型和边界|与授权规则一致；沿用原事务或逐项回执，不产生未声明的部分成功|
|QT05|报告周期1、90、10.0、1e1以及非边界合法值|按精确整数成功，保留原有排程语义|
|QT06|报告周期缺失/null、0、91、小数/极小小数、溢出、字符串/布尔/容器|400；不改变计划版本、Quartz 配置或成功审计|
|QT07|创建、更新及可达的导入/同步入口|同一字段规则；精确输入不能先经过有损转换|
|QT08|历史记录可读与旧版本冲突|不批量修改旧数据；项目权限、乐观锁与428/409规则不变|
|QT09|页面原始输入及编辑|小数不得先舍入后提交；提示字段，缺失和越界阻止写请求|
|QT10|非目标字段与其他功能|现有契约及相关套件保持；不发送真实外部通知|

环境使用自有隔离测试数据，正式结果以实际执行为准；12项环境补齐和其余9项观察暂缓，升级关闭超时独立保留为根因未确认。
