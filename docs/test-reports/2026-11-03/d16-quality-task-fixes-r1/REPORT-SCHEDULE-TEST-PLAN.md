# D16 质量报告计划后端测试设计

依据已批准的 D16-I/N/NULL/OLD A 和 D16-AC-27～33。只覆盖报告计划的 periodDays，保留 expectedVersion、Cron、权限、Quartz 调度、迁移和同步事务契约。此文件在代码修改与运行测试前创建。

| 编号 | 类型 | 输入/入口 | 预期 |
|---|---|---|---|
| QR-01 | 正例 | 创建/编辑 periodDays 1、90、10、10.0、1e1 | 成功；精确值存储，计划版本与 Quartz 按原规则更新 |
| QR-02 | 反例 | 0、91、-1、1.5、10.0000000000000001、大指数、溢出 | 400；无新计划、版本、Quartz、成功审计变化 |
| QR-03 | 反例 | 数字字符串、布尔、数组、对象、null、缺失 | 400；无部分变更 |
| QR-04 | 正反 | 迁移原始 JSON 精确等值、微小小数、缺失、越界、非有限数和错误类型 | 合法精确整数接收；非法请求无迁移回执及部分计划 |
| QR-05 | 正反 | 同步原始 JSON 10、10.0、1e1 和微小小数、缺失、越界、非有限数和错误类型 | 以原始精度判定，等值成功；非法请求无写入/回执 |
