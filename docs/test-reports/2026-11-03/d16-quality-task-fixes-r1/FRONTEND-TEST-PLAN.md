# 质量报告与任务 D16 前端回归设计

依据已批准 D16-I-A、D16-NULL-A 及 D16-AC-25~28、32。输入保留原始文本，校验后发送 JSON 数字；非法输入拒绝且不发生业务请求。以下用例先于实现记录。

| 编号 | 入口及输入 | 预期 |
|---|---|---|
| QF-01 | 编辑任务进度 0、100、10.0、1e1 | 发送对应整数，保留版本 |
| QF-02 | 编辑任务进度空、-1、101、1.5、10.0000000000000001、大指数、非数值 | 提示并阻止 PUT；不因状态归一化绕过 |
| QF-03 | 新建任务 | 按原契约创建，不新增进度字段 |
| QF-04 | 新建报告周期 1、90、7.0、7e0 | 发送整数 |
| QF-05 | 新建/编辑报告周期空、0、91、1.5、7.0000000000000001、大指数、非数值 | 提示并阻止写入，保留草稿 |
| QF-06 | 编辑报告周期合法值 | 原版本信息随请求发送；冲突草稿行为不变 |
| QF-07 | 编辑状态 QUEUED/SUCCEEDED 且进度非法 | 在前端阻止请求；状态机仍由后端处理 |
