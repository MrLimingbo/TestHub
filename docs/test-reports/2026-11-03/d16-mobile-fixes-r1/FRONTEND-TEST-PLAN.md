# 移动端 D16 前端测试设计（执行前）

依据已审核 D16-AC-22、23、32：保持原始输入直至精确整数验证；步骤超时 1..60000，空值采用服务端 30000 默认；执行超时 10..3600，空值 300。场景变量对象值必须为字符串，null、数字、布尔和容器拒绝；设备能力参数不变。非法值不得发起写请求或启动本地 Appium。

| 编号 | 情况 | 预期 |
|---|---|---|
| MF-01 | 步骤 1、60000、1000.0、1e3 | 精确提交对应整数 |
| MF-02 | 步骤 0、60001、小数、极小小数、大指数、非数值 | 字段提示，阻止提交 |
| MF-03 | 步骤空值 | 不发送该值，由服务端默认 30000 |
| MF-04 | 执行 10、3600、300.0、3e2、空值 | 提交整数，空值 300 |
| MF-05 | 执行越界、小数、极小小数、非数值 | 阻止入队，且 Appium 准备前拒绝 |
| MF-06 | 变量值字符串、空串、模板字符串 | 原值提交 |
| MF-07 | 变量值数字、布尔、null、数组、对象 | 阻止提交，提示变量类型 |
| MF-08 | 编辑、多步骤修改/删除 | 各步骤原始输入独立，无界面字段进入请求 |
