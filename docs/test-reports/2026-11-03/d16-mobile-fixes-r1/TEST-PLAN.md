# 移动端自动化 D16：回归设计

范围：OBS-12-E020，按已批准 D16 规则 A 组合；本设计先于本轮验证执行。目标字段为步骤 timeoutMillis（1..60000，默认30000）、执行 timeoutSeconds（10..3600，默认300）、variables 值、步骤 value 和 expectedText。保留既有必填、空值、长度、步骤类型及权限规则；设备 capabilities 和跨平台定位器不在本轮范围。
