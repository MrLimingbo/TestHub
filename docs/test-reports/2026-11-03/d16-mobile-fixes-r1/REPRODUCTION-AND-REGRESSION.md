# 移动端 D16 复现与回归记录

观察 `OBS-12-E020`：原移动端输入边界对整数与文本存在隐式转换，可能改变用户提交值。以下为不同触发路径，按同一观察跟踪，不重复计为多个历史 Bug。

## 场景步骤超时被截断

前提：隔离测试项目中已创建同平台设备和应用，使用有写权限的账号。

1. 向 `POST /api/v1/projects/{projectId}/mobile-automation/scenarios` 提交包含 LAUNCH 步骤的合法场景，在原始 JSON 中设置 `steps[0].timeoutMillis` 为 `1000.5`。
2. 修复前输入绑定使用的整数转换可能将小数转成整数；未保留此接口修复前的独立 HTTP 红测。解析器测试验证历史存储读取仍有此兼容行为。
3. 期望：返回 400 和可定位的安全错误，场景及审计等计数不增加；`1000.0` 和 `1e3` 按精确整数接受。新增定向测试检查极小小数、数字字符串及错误 JSON 类型。

## 文本值被隐式转换

1. 用相同入口构造合法场景，将步骤 `value` 或 `expectedText` 改为 JSON 数字、布尔值或对象；也可将 `variables` 中某个值设为数字。
2. 修复前解析可把数值或布尔值转为字符串，产生与原始请求不同的场景内容。
3. 期望：返回 400，不持久化；明确的字符串 `"001"` 保持原文，变量值为 null 仍被原业务规则拒绝。错误中不回显输入内容。

## 畸形运行清单进入设备会话

1. 使用受控 Runner 夹具返回一份其余字段合法、步骤 `timeoutMillis` 为 `1.5` 的运行配置。
2. 修复前 Runner 未拒绝该配置，能继续进入 Appium 会话请求；此前新增的5组协议测试中4组失败。
3. 修复后在设备会话创建前返回受控失败；测试断言仅发生控制面配置请求，未发起 session 请求。旧排队清单的原始类型也在控制面发放前检查。

本记录中的模拟设备农场及受控协议检查不代表连接真实 Android 或 iOS 设备。历史精度已经丢失的值无法反推，旧数据不批量改写。
