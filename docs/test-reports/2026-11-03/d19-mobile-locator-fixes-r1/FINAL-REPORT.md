- 元素创建/编辑使用统一平台矩阵；导入和同步复用服务校验，非法组合返回受控400。拒绝的更新保留旧值和时间戳，交换拒绝不产生部分资料或成功回执。

- 冻结清单发放前校验设备平台与定位策略，再进入原有执行认领逻辑；坏清单保持QUEUED。合法冻结清单不因源元素后来改为非法而改变，也不自动取消运行中的任务。
- Runner在Appium会话创建前检查带定位器或需要元素的步骤；合法矩阵接受，跨平台、未知/缺失策略、定位值或平台受控失败。无定位器的LAUNCH/WAIT/SCREENSHOT保留原非目标契约。
- 页面按平台提供4个选项；新建时切平台清除不兼容策略、保留通用策略；历史非法组合直接保存会阻止写请求并提示，合法编辑携带原expectedUpdatedAt。

这些是同一项观察的多个触发面，不新增为多个历史Bug。修复前后端4通过/6失败、页面1通过/3失败、Runner2通过/2失败；循环首失败后未执行的后续变体不冒称已复现。Runner夹具默认值与事件代码断言修正、报告统计脚本匹配错误日志前缀的修正属于资产/执行维护，不计产品缺陷。页面选项红测中的TypeError发生在测试读取旧组件选项时，不是已证实的页面崩溃。
