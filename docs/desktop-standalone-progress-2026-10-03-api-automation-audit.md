## 已确认的基线

- 桌面运行时已内置 Java、前端与独立 API Runner。新工作区默认关闭外部 HTTP 执行；用户可在原生“本地执行设置”中精确授权目标 Origin，重启后 Runner 从本机队列接任务。控制面不直接执行用户脚本。
- 2026-10-03 用当前运行组件和全新用户目录重跑真实 Electron 流程，**7/7** 通过：无授权默认态、非法地址拒绝、授权后身份保持、真实本机 HTTP 成功、未授权目标零请求、重启后场景及授权保留、撤销后无法发请求。证据在 `.testhub/api-automation-module-20261003/baseline.log` 与 `baseline-result.json`。
- 另一全新工作区的资产与执行流程 **9/9** 通过：公共步骤 v1→v2、运行配置、引用执行、JSON 数据集两行真实请求、报告导出 SHA-256、定时计划显式启用后手动运行、Webhook 密钥仅创建时展示、签名触发与 nonce 重放拒绝、重启后资产与页面可用。证据在 `.testhub/api-automation-module-20261003/assets-flow.log` 与 `assets-flow-result.json`。这里的签名触发从本机回环发起，不代表外部 CI 能直接连接本机应用。
- 页面和后端现有资产包括场景/修订、公共步骤/修订、数据集及来源文件、运行配置集、计划、Webhook、执行任务/结果/报告。旧版线上功能测试见 `api-automation-qa-2026-09-09.md`，不能替代当前桌面整模块验收。
- 扩展流程发现计划无法选择运行配置集，依赖该配置变量的场景只能手动运行。现已为计划新增可选 `executionProfileId`，原有计划保持空值；手动与 Quartz 触发均复用执行服务的现有冻结逻辑，页面可选择配置集。新建桌面 V10 / MySQL V67 迁移已通过隔离 H2 全套 **288/288**、全新 MySQL 计划专项 **4/4**；前端 **126/126**、lint、生产构建及 Runner **42/42** 通过。真实桌面改动后 **10/10**：计划发出的请求使用所选配置变量、重启后编辑页回显配置，证据见 `.testhub/api-automation-module-20261003/assets-flow-profile-ui.log`。

## 本轮完成

- 修复定时计划缺少运行配置选择的问题：原有计划仍可保持空配置，新增计划可选项目内配置，手动和 Quartz 触发均使用该配置。桌面 H2 V10、MySQL V67 迁移已验证。
- 新增接口自动化 V1 账号迁移：场景与公共步骤的全部修订、引用重映射、数据集完整行与来源文件、当前运行配置及其版本、定时计划。计划在目标端一律停用；Webhook 密钥不可读回，目标端重新创建。目标项目必须已有对应且启用的运行环境。迁移为一次性复制，预览只读，确认后才上传，账号或服务切换会使预览失效；UUID 幂等回执和目标项目事务锁防止重试重复写入。桌面 H2 V11、MySQL V68 迁移已验证。
- 原生入口新增“接口自动化资料迁移”，加载项目完成前入口保持禁用。接口自动化快照最大 32 MiB，来源文件逐个校验大小和 SHA-256，目标文件复制有持久化清理意图；数据集、场景、配置和计划经原业务服务重新校验。目标端可由独立浏览器读取迁入资产，本地原件保持不变。
- 验证：最新隔离 H2 全套 **292/292**（含迁移 4 项），全新 MySQL/Redis 容器专项 **8/8**，桌面单测 **103/103**，Runner **42/42**，前端 **126/126**；lint、前端类型检查及生产构建通过。最新代码的真实 Electron 账号迁移 **7/7**，从最终内部 Mac arm64 包提取应用代码和运行时后再次 **7/7**。证据位于 `.testhub/api-automation-module-20261003/transfer-backend-release.log`、`transfer-mysql-tests.log`、`transfer-desktop-final.log`、`transfer-electron-fixed.log` 和 `transfer-package-release-qa.log`。最终内部包在 `.testhub/api-automation-module-20261003/package-release/mac-arm64/TestHub.app`，包内 JAR 与构建产物 SHA-256 相同，清单 `distributionReady=false`；未签名、公证、安装或发布。
