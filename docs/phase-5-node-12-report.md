# 阶段 5 · 节点 5.12：冻结非敏感运行时变量

## 交付内容

- 每次创建接口自动化执行时，在同一事务内写入不可变的 `api_automation_execution_runtime_snapshot`。
- 快照只固化当前场景实际引用、且最终来源为场景变量或项目参数的非敏感取值；来源优先级保持环境密钥、场景变量、项目参数。
- 环境密钥只从元数据查询中取得名称，并写入 `withheldSecretNames`；不读取密文、不解密、不写入取值。
- 增加项目读取权限保护的运行时快照审阅接口；响应只含名称、来源、计数、环境与校验和，绝不返回非敏感值或密钥值。
- 接口自动化任务详情抽屉增加“冻结非敏感运行时变量”面板，明确标注取值不对外展示、运行时配置交接仍关闭。

## 安全边界

- Redis Stream、Outbox、执行记录、日志、浏览器页面和 Runner 租约接口均不传递快照取值。
- 环境密钥在此节点仍无领取或执行入口，`RUNTIME_CONFIGURATION_DISABLED` 不变。
- 后续修改场景变量或项目参数不会改变已经提交任务的快照。

## 验收建议

1. 在接口自动化页提交一个引用场景变量、项目参数和环境密钥的场景，再打开任务详情。
2. 确认面板显示非敏感变量的名称与来源、环境密钥名称和校验和，但没有任何变量取值。
3. 修改项目参数后重新打开已提交任务，确认原快照计数与校验和不变；新任务才会使用更新后的值。
