## 使用与范围

桌面移动端自动化页面和应用菜单新增“移动端资料同步”。连接账号服务并登录后，显式选择本地项目及账号项目，先预览上传、下载、冲突、排除的执行历史和应用包关联，再通过默认取消的确认建立绑定。默认不上传。绑定后应用运行时每 30 秒双向检查新建及修改，断网可继续编辑本地，联网且会话有效后自动重试。支持立即同步、暂停、恢复、解除绑定和冲突选择；退出 App 后不运行同步。

| 类型 | 同步定义 |
| --- | --- |
| 设备 | Android/iOS 平台、UDID、自动化引擎、白名单能力参数 |
| 应用 | 平台、应用标识、版本名称 |
| 元素 | 平台、定位策略、定位值、说明 |
| 场景 | 设备/应用引用、说明、失败策略、变量及全部七种有序声明式步骤；步骤元素引用按名称重映射 |

按类型及名称匹配，引用映射为目标端自己的 ID。Map 键顺序不构成冲突，步骤顺序有意义。已有 ID、创建信息、启停状态和应用包文件关联保留各端；设备、应用及场景更新递增本端版本，元素更新使用原有单调递增毫秒令牌。新设备和应用停用，新应用没有文件关联，场景从版本 1 开始。

同名不同内容或双端均修改需选择。确认期间再次修改则拒绝过期决定。平台不允许覆盖；同名平台不同、名称大小写不同、重复 UDID、引用缺失或引用平台不同需手动核对。冲突版本会撞上另一设备 UDID 时也不能确认覆盖。父资料待核对时相关场景暂停，其他可独立同步的资料继续。删除不传播，也不自动重建；改名按新名称处理，原名称缺失仍需核对。完整冲突定义放在可键盘滚动的区域，轮询保留冲突按钮焦点。

确认披露 UDID、能力参数、变量及步骤内容会发送到所选账号服务。APK/IPA、执行历史、报告、截图、Appium 服务地址、设备运行环境、SDK/驱动及授权不复制。已有应用包关联保持且文件字节不变。同步不调用 Appium、不提交执行；已经提交的任务继续使用冻结清单。需要执行时仍须在本端准备 Appium、设备及相应运行环境。

每类每项目最多 100 条（合计最多 400），场景最多 300 步；快照及合并定义最多 3 MiB，POST 和原生 HTTP 响应最多 4 MiB。合并数量包含基线中待核对的缺失资料。`excludedFiles` 统计应用包关联数量，多个应用引用同一文件时按多个关联计数。

## 一致性与保护

- GET/POST `/api/v1/projects/{projectId}/mobile-automation/sync`，版本 1、范围 `MOBILE_AUTOMATION_SYNC`。GET 使用 `expectedUserId`；POST 使用 UUID `requestKey`、准确账号、目标 `expectedRevision` 和带 UUID 的 `operations`。操作只接受 `{kind,name,definition}`，不接受文件 ID、启停、历史或脚本字段。
- 沿用原有移动端写入角色，校验项目权限、准确账号、CSRF、字段规范化、重复名称/操作、完整引用和数量/字节界限；未知字段、尾随 JSON、不支持的能力参数及脚本步骤均拒绝。无新增依赖。
- 快照使用一致读事务；摘要包含本端 ID、版本、启停、应用文件关联、更新时间及定义，Map 稳定排序。读取前检查 SQL 数量和大字段字节数。
- CRUD、一次性迁移、同步及执行的冻结配置读取使用相同项目锁。写入在 READ_COMMITTED 下等待锁后读取当前资料，继续使用原有乐观编辑令牌。过期摘要、平台/UDID/名称/引用冲突、大小超限、审计失败和数据库约束错误整批回滚。
- 提交前持久保存准确请求和 UUID。项目/账号/requestKey 唯一回执使提交成功但响应丢失后返回原结果；重放不重复创建、递增版本或覆盖之后的修改。
- `mobile-automation-sync.bin` 使用系统安全存储加密、原子落盘、0600 权限，存于工作区之外。保存绑定、基线、冲突及待确认请求，不保存密码或令牌；损坏时保留文件并报错。
- 复用已审核的 IPC/HTTP 与加密存储，只信任本模块原生页面及主框架。七种同步独立绑定、每种一组项目，与备份/迁移共用操作互斥；恢复备份前持久暂停全部七种绑定并要求重新预览。

新增 H2 V26 / MySQL V83 `mobile_automation_sync_receipt`。原编辑、一次性迁移、执行及报告契约不变，六份旧同步文件格式不变。
