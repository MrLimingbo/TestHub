## 对象与方法

使用上一模块最终 DMG `release/desktop/preview-24ae96a-20261019/TestHub-macOS-arm64-preview.dmg` 的独占临时副本，安装器 SHA-256 为 `1a0aad486e3fbdaa725356940b3a263c7dd10f4c72960b019038cbbec7d9fc91`。包构建时的工作树打包输入已与提交后的 main 核对一致；本轮不修改业务代码、组件版本、下载地址、校验值或 ASAR，因此无需重新生成相同业务程序的安装器。

复用脚本为 `scripts/desktop/accept-first-downloads.mjs`，仅支持原生 Mac。它在实际打包入口暂停后建立独立数据目录、隐藏离屏窗口及下载观察，再恢复未经修改的包入口。浏览器和 JMeter 初始缓存均不存在，没有复制历史缓存、安装标记或浏览器文件。成功下载经应用原有的官方 HTTPS 通路、固定大小及摘要校验、真实解压、启动和就绪探测后才可执行。

故障验收通过 QA 引导拦截组件下载请求，分别模拟离线和接收部分真实网络字节后的断流；取消通过界面按钮触发。未改变电脑网络设置，也没有关闭 TLS 或放宽组件校验。重启复用验收仅阻断组件下载网络，测试目标始终是自有回环服务。

## 复验、清理与边界

先从最终 DMG 以只读、隐藏方式提取独占应用副本并执行 `codesign --verify --deep --strict`，再运行：

```bash
node scripts/desktop/accept-first-downloads.mjs \
  --app <owned-extracted-TestHub.app> --output <new-summary.json>
node --test apps/desktop/test/local-engines.test.cjs apps/desktop/test/local-browsers.test.cjs
```

摘要路径必须不存在，脚本预留 `passed=false` 状态，未完成时不会复用旧成功结果。测试需要真实组件下载网络；故障注入属于 QA 进程，成功下载不使用本地替代归档。输入应用副本归调用方所有，阶段结束后需另行删除该副本，不能传入或清理用户已安装程序。
