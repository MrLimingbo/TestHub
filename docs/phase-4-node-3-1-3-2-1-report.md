# 阶段 4 · 节点 4.3.1.3.2.1：WebSocket 基础调试

**状态：待产品验收**

## 本节点交付

- 接口调试器新增 WebSocket 协议，可建立 `ws://` / `wss://` 文本会话、发送消息、以两秒轮询读取收到的消息，并支持手动关闭。
- WebSocket 会话、消息和连接状态只保存在控制面的短期内存中；原始消息、请求头和连接地址查询参数均不写入数据库、执行历史或审计详情。
- 会话按用户和项目隔离；连接、发送、关闭均要求项目写权限，读取消息和会话要求项目读权限。
- 会话数量限制为每用户每项目 10 个；每个会话保留最多 100 条消息，单条消息接收与发送上限均为 32000 字符。
- 连接目标复用接口调试器的公网限制：拒绝回环、内网、链路本地、多播、保留地址和 URL 用户信息；同时拒绝由客户端生成的 `Upgrade`、`Connection`、`Sec-WebSocket-*` 等握手请求头。
- JDK WebSocket 客户端按片段处理文本帧，限制拼接大小并将异常状态回传为安全的通用提示；控制面不执行用户脚本。

## 当前兼容边界

- 本节点仅覆盖文本消息、手工请求头、连接、轮询和关闭。
- WebSocket 的环境变量解析、认证配置、子协议/订阅以及自动重连在下一小节点实现。
- 二进制帧不在页面展示；gRPC 仍为后续独立节点。
