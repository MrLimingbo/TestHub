# 阶段 7 · 节点 2：跨项目质量报表

完成时间：2026-07-22

## 交付范围

- 新增 `GET /api/v1/reports/quality`：在当前用户可访问的项目范围内汇总功能用例、接口定义、自动化场景、未关闭缺陷、执行结论、每日趋势与项目健康状态。
- 支持重复或逗号分隔的 `projectIds` 参数，以及 `from`、`to` 自定义日期范围；默认统计最近 30 天，范围限制为 1–90 天，单次最多 50 个项目。
- 新增 `GET /api/v1/reports/quality/export`：导出 UTF-8 BOM CSV，包含摘要、每日趋势、项目健康度；所有单元格均处理电子表格公式前缀，并为每个导出范围写入审计记录。
- 将报表页替换为真实跨项目报表：可访问项目多选、自定义开始/结束日期、质量摘要、趋势图、健康度表格和 CSV 下载。
- 看板数据聚合增加结束日期上界，避免日期范围查询包含范围外的后续执行记录。
