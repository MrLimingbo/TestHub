# 阶段 4 · 节点 4.3.1.2：调试环境、认证与动态值

**状态：待产品验收**

## 本节点交付

- 调试器可选择项目环境，并列出该环境的项目参数和环境密钥名称；环境密钥的明文不会返回给浏览器。
- 请求 URL、请求头、请求体和认证字段支持 `{{VARIABLE_NAME}}` 变量替换。
- 支持动态值：`{{$timestamp}}`、`{{$isoTimestamp}}`、`{{$randomUUID}}`（`{{$uuid}}` 同义）。同一请求内的 UUID 与时间值保持一致。
- 支持认证类型：无认证、Bearer Token、Basic Auth、API Key（Header 或 Query）。认证配置仅用于本次请求，不写入执行历史。
- 环境密钥继续使用 AES-GCM 加密保存；新增服务端解密路径，仅在执行请求时读取。

## 密钥与审计边界

- 浏览器只读取项目参数值和环境密钥名称；密钥明文只在服务端插值和构造认证头时短暂使用。
- 历史记录不保存请求头、认证字段、请求体或响应体；若 URL 中包含环境密钥值，会替换为 `***`，既有敏感查询参数名也继续脱敏。
- 审计记录只保留方法、环境和执行状态，不记录目标主机或认证信息。
- 本节点不包含 Cookie、代理、客户端证书、重定向策略或用户脚本执行。
