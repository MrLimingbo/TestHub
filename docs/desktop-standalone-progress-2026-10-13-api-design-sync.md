# 接口设计资料持续双向同步（已审核通过）

本模块在已通过的本地工作区、项目文件和文件链接同步基础上，增加 `API_DESIGN_SYNC / 1`。用户在接口设计页或原生菜单打开同步窗口，明确选择本地项目与账号项目，预览并确认后，目录树、请求方法与路径对应的接口元数据、版本及调试用例可持续双向同步。登录账号、项目权限和启用状态每次运行都会核对；断线时保留加密基线与待确认请求，恢复后使用持久请求键重试。

目录按完整路径、接口按方法与路径、版本按接口及版本名、用例按接口及名称对应，不传递两端的物理 ID。相同项目内的删除、改名或同名重建会暂停有关资料，不自动重建或删除。目录、定义与当前版本的依赖冲突会暂停相关资料，无关资料仍可继续。用例引用的目标环境须已存在且启用；gRPC 描述符引用因尚未配对而暂停。正文项目文件链接只在前一模块已配对且文件完好的情况下映射到目标路径。单次同步至多 300 条、8 MiB；服务端有项目锁、修订校验、CSRF、权限验证、事务与幂等回执。

用户在本阶段明确选择**允许覆盖同名历史版本的内容**。单边变化可同步；两端同时修改或首次同名内容不同，需要选择保留哪端内容。覆盖保留目标端原版本 ID、创建信息、发布人和发布时间。发布状态可以从草稿升为已发布；已发布状态不会因内容选择而撤销。已有接口的公开编辑 API 保持原行为，这项覆盖仅由受校验的同步协议执行。当前版本指针在同批版本写入后按逻辑版本名恢复。调试执行结果、草稿历史及自动化场景不在本协议范围。

数据库新增 H2 V38／MySQL V95 幂等回执表。Mac arm64 内部实验包包含更新后的本地服务与前端，`distributionReady=false`，并非正式公开发行验证；Windows、Mac Intel 的安装包及干净机器首启不在本阶段验收范围。
