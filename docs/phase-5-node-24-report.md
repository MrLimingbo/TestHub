# 阶段 5 · 节点 24：运行配置集管理与提交前来源预览

## 交付内容

- 场景运行配置集新增 Web 编辑入口，读取当前版本后使用已有的乐观锁更新接口提交；更新成功会产生新的配置集版本，既有执行任务继续关联其创建时的旧版本。
- 新增只读接口 `POST /api/v1/projects/{projectId}/api-automation/scenarios/{scenarioId}/execution-configuration-preview`。它接收可选配置集和一次性覆盖变量，复用实际执行的变量解析器返回最终环境、配置集版本、引用变量名称、来源及使用位置。
- 预览不会创建执行记录、Outbox、审计事件、运行时快照或任何 Runner 消息；变量和环境密钥取值始终不在响应中出现。
- “提交场景执行”弹窗新增“预览最终来源”。更换配置集或覆盖 JSON 会使旧预览失效，避免误将过期预览当作当前提交结果。

## 安全边界

- 预览使用与提交相同的项目执行权限、变量合法性、未定义变量、局部变量顺序和环境密钥同名覆盖校验。
- 输出只包含来源元数据；不会返回请求地址、步骤配置、变量值、项目参数值或密钥值。
- 数据集逐行执行不使用此预览接口；它仍保持自己的行级冻结链路。

## 验证

- `ApiAutomationExecutionProfileFlowTests` 覆盖无执行副作用的来源预览、配置集版本更新和脱敏响应。
- 前端 lint 与生产构建通过。
