## 修复内容

| 问题 | 修复与验证 |
| --- | --- |
| Redis RESP3 对象被忽略 | 兼容对象/数组响应，任务消费回归由失败转通过 |
| CONTINUE 后错误返回成功 | 保留全部步骤结果，存在失败时执行最终失败 |
| CONTINUE 吞掉取消/超时 | 立即传播控制信号，取消后不执行后续步骤 |
| 未定义变量变成空文本 | 发送输入前明确失败 |
| null 步骤触发 500 | 控制器与服务校验，真实 HTTP 返回 400 |
| 重复步骤 ID 可保存 | 校验步骤 ID 唯一，真实 HTTP 返回 400 |
| Android/iOS 引擎不匹配可保存 | 拒绝已知跨平台引擎组合；页面切换平台同步默认引擎 |
| 保存/执行失败后关闭弹窗 | 提交前回调明确返回结果，表单保持可修正 |
| 项目切换、报告刷新与迟到响应 | 资源请求序号隔离，关闭旧弹窗；报告轮询、错误显示及迟到响应保护 |
